# SaGe：通过场景图思维强化多模态大语言模型的结构化视觉推理

## 研究问题与动机

### 核心问题

当前 MLLM（多模态大语言模型）在视觉推理中面临"扁平化"瓶颈：

1. **视觉信息扁平化**：图像被编码为无结构化的 token 序列，丢失了对象关系、属性层次等结构化信息
2. **推理粒度粗糙**：模型倾向于整体"感觉"而非逐步"推理"，在细粒度视觉问答中容易出错
3. **缺乏结构化监督**：训练数据中的文本描述往往只是对图像的平铺叙述，缺乏显式的视觉关系标注

### 核心洞察

**场景图（Scene Graph）是连接视觉感知和语言推理的理想中间表示**：
- 节点 = 对象/属性
- 边 = 视觉关系（空间、比较、动作...）
- 结构化 = 可验证、可操作、可迁移

如果让 MLLM 学会"用场景图思考"，结构化推理能力应能系统性地提升。

## 方法概述

SaGe 框架包含三个核心组件：

```
阶段 1: 自动场景图生成引擎
  扁平图文 → 场景图 + 推理链
  ↓
阶段 2: SFT 图对齐训练
  模型学会"看图生成场景图 + 推理"
  ↓
阶段 3: RL 图奖励精调（GRPO）
  节点级图奖励引导探索
```

### 组件 1：自动数据引擎

- 输入：扁平图像-文本语料（如 COCO、VG）
- 输出：120K 高质量训练样本（场景图 + 图对齐推理链）
- 过程：利用 LLM 自动解析图像描述 → 提取对象/属性/关系 → 构建层次化场景图 → 生成基于图的推理链

### 组件 2：SFT 图对齐训练

- 模型学习：给定图像 → 生成场景图描述 → 基于图进行推理 → 回答问题
- 内部化了结构化的"以图思考"模式

### 组件 3：RL 图奖励精调（GRPO）

- 使用 GRPO（Group Relative Policy Optimization）进行强化学习
- **核心创新：节点代理图奖励（node-as-proxy graph rewards）**
  - **节点接地奖励**（node-grounded）：生成的推理是否正确引用了场景图中的节点
  - **节点相关性奖励**（node-relevance）：引用的节点是否与问题相关
- 无需逐条人工标注，图结构本身提供监督信号

### 节点代理图奖励详解

传统的 RL 奖励需要人工标注或结果验证，SaGe 的场景图结构本身提供"免费"的监督信号：

- **节点接地奖励**：生成的推理步骤中提到了 X，但场景图中有 X 吗？有 = 正奖励
- **节点相关性奖励**：问题问的是 A 和 B 的关系，推理中正确引用了 A 和 B 的节点吗？正确 = 正奖励

这种设计使得 RL 训练无需额外的人工标注成本。

## 关键创新

1. **从扁平到结构化的范式迁移**：首次系统性地将场景图作为 MLLM 推理训练的中间表示
2. **自动数据引擎**：120K 样本完全自动生成，无需人工标注场景图
3. **节点代理图奖励**：利用图结构本身提供 RL 训练信号，零额外标注成本
4. **两阶段训练（SFT + RL）**：SFT 内化结构化思维，RL 精细调优
5. **通用性验证**：在 8 个不同性质的基准上一致提升，证明方法不依赖特定任务

## 实验与结果

### 基准覆盖

在 **8 个多模态基准** 上验证：
- 细粒度感知（如对象计数、属性识别）
- 关系推理（空间关系、比较推理）
- 视觉问答（VQA）
- 图像描述与 grounding

### 关键结果

- 在全部 8 个基准上取得显著提升
- 尤其在需要细粒度视觉推理的任务上增益最明显
- GRPO + 节点代理奖励比纯 SFT 有额外增益
- 消融实验证明场景图结构化表示（而非简单的文本描述）是关键

### 消融实验

- 无场景图的基线 vs 有场景图：结构化表示带来最大增益
- 仅 SFT vs SFT + RL：RL 阶段提供额外提升
- 全图奖励 vs 节点代理奖励：节点级细粒度奖励优于整体图级奖励

## 深度分析

### 优势

1. **结构化可解释**：场景图提供了模型推理的可视化解释——可以追查模型"看到了什么"
2. **数据效率**：120K 自动生成数据即可有效训练，无需百万级人工标注
3. **训练效率**：两阶段设计收敛快，RL 阶段仅需少量额外计算
4. **通用范式**：场景图可以替换为知识图谱、程序图等其他结构化表示

### 局限

1. 自动生成的场景图质量受限于 LLM 的能力——如果 LLM 在复杂场景中生成错误图，会传播错误
2. 场景图表示对某些视觉概念（如纹理、情绪）的表达能力有限
3. 仅在相对较小的 MLLM 上验证，在更大规模模型上的效果未知
4. 图结构引入额外的推理步骤，可能增加延迟

### 展望

- 场景图思维可以扩展到视频理解——时序场景图
- 与外部知识图谱的融合：场景图 + 世界知识图
- 实时场景图生成和查询的能力
