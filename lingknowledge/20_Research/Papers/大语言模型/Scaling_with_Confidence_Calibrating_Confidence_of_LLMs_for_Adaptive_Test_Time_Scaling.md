## 摘要

### 核心要点提炼
- **研究背景**：测试时计算扩展（Test-Time Scaling）是提升 LLM 推理性能的关键技术，但现有方法（如多数投票）计算开销与性能提升不成正比
- **研究动机**：如何在保持推理准确率的同时，大幅降低测试时计算成本？
- **核心方法**：提出 C3RL（强化学习联合优化正确性+置信度校准）和 CAS（基于置信度的自适应推理策略）
- **主要结果**：CAS 在保持或超越多数投票准确率的同时，将计算预算降低高达 12.33 倍
- **研究意义**：为推理时计算扩展提供了一种智能的、基于置信度的资源分配方案

## 研究问题

**核心研究问题**：如何实现自适应的测试时计算扩展——在简单问题上节省计算、在困难问题上增加投入？

具体而言：
1. 如何训练 LLM 生成更准确的置信度估计？
2. 如何基于置信度动态决定是否需要更多推理步骤？
3. 如何在计算预算与推理准确率之间取得最优平衡？

## 方法概述

### 核心方法

1. **C3RL（Calibrated Confidence + Correctness RL）**
   - 设计了一种强化学习算法，同时优化两个目标：生成答案的正确性 和 置信度的校准质量
   - 奖励信号包括：答案是否正确、置信度是否与实际准确率一致
   - 使模型学会"知道自己何时知道答案"

2. **CAS（Confidence-based Adaptive Scaling）**
   - 基于模型输出的置信度分数，动态决定是否启用更多推理路径
   - 高置信度 → 直接输出，节省计算
   - 低置信度 → 启动多条推理链（如 Beam Search 或多次采样），综合判断
   - 自适应地在简单样本上节省资源，在困难样本上增加投入

### 关键创新

1. **联合优化正确性与置信度**：C3RL 将置信度校准融入 RL 训练目标，而非后处理
2. **自适应资源分配**：CAS 根据样本难度动态调整计算预算，而非一刀切
3. **显著的计算节省**：最高 12.33x 计算预算降低且性能不降

## 实验结果

### 实验设置
- **测试基准**：多个数学推理和多步推理基准
- **基线方法**：多数投票（Majority Voting）、Best-of-N 采样、Self-Consistency
- **模型**：使用标准数学推理 LLM 进行实验

### 主要结果
- CAS 以 1/12.33 的计算预算达到甚至超越多数投票的性能
- 在多个基准上，C3RL 训练的模型置信度校准质量显著优于标准 SFT 模型

## 深度分析

### 研究价值
- **理论贡献**：将置信度校准从"后处理"提升为"训练目标"，统一了推理质量与推理效率的优化
- **实际应用**：对有推理预算限制的部署场景（如 API 调用、边缘设备）具有直接价值
- **领域影响**：为"自适应推理"范式提供了系统性的训练+推理框架

### 优势
- **计算效率极高**：最高 12.33x 预算节省
- **方法统一**：一次训练，自适应推理
- **可叠加**：CAS 可与现有推理增强方法（如 CoT、Self-Consistency）结合

### 局限性
- **需要额外 RL 训练**：C3RL 需要 RL 训练阶段，增加了初始成本
- **置信度校准的泛化性**：在分布外数据上的置信度校准质量待验证
- **奖励设计敏感**：RL 训练的效果依赖于奖励函数的设计

### 适用场景
- **大规模推理服务**：降低 API 调用的计算成本
- **资源受限环境**：边缘设备上的 LLM 推理
- **批处理推理**：对大量样本进行高效推理
