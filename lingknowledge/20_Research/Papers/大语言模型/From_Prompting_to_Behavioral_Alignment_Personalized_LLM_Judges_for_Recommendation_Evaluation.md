# From Prompting to Behavioral Alignment: Personalized LLM Judges for Recommendation Evaluation

## 一句话总结
用 LLM 替代推荐系统离线评估中昂贵的手工特征管线，但发现 off-the-shelf LLM 存在**"双向合理化"**（对同一证据能同时论证正反两面）的致命缺陷，于是提出**行为对齐框架**（微调 + 偏好优化），把 Macro-F1 提升 32.19% 并匹配生产基线。

## 研究问题

### 核心研究问题
传统离线推荐评估依赖复杂、手工维护的特征管线（feature pipeline），难以扩展。LLM 能直接从原始文本日志预测用户参与度，看起来是理想替代品。但要回答：**off-the-shelf LLM 是否真的可靠？如何让它可靠？**

### 研究动机
- 特征管线昂贵、难维护、不可扩展；
- LLM 能直接读文本日志，省去手工特征；
- 但 LLM 直接当"评判器（judge）"预测用户行为，其可靠性未被严格检验。

## 方法概述

### 核心思想

![[task_setup.png|700]]

> 图1：任务设置——LLM 从用户交互日志预测用户参与度（替代手工特征管线）。

**问题：双向合理化（bidirectional rationalization）**
在 zero-shot 设置下，作者发现 LLM 对**同一个 item、完全相同证据**，能"头头是道"地论证两个相反结论：
- "用户会点击/参与"
- "用户不会点击/参与"

这说明 off-the-shelf LLM 的推理是"事后合理化"而非"真实因果判断"，作为评判器不可靠。

**方法：顺序行为对齐框架（sequential behavioral alignment）**
1. **微调（fine-tuning）**：先在下游数据上微调 LLM；
2. **偏好优化（preference optimization）**：在"正确 rationale vs 反事实（counterfactual）rationale"的成对数据上做偏好优化，让模型学会偏好真实的行为解释。

### 关键创新
1. **识别并命名了"双向合理化"失败模式**：这是 LLM-as-judge 在推荐评估场景的一个关键失效点。
2. **用行为对齐（而非纯提示工程）修复**：从"prompting"升级到"alignment"，用偏好优化直接纠正推理方向。
3. **保留可解释性**：对齐后的模型输出人类可解释的推理轨迹（reasoning trace），而不是黑盒打分。

## 实验结果

### 主要结果
- **Macro-F1 提升 32.19%**：对齐后的推理方法相比 zero-shot 基线；
- **匹配生产基线**：达到生产环境特征工程基线的同等水平；
- **缓解双向合理化**：行为对齐后，模型不再对同一证据给出自相矛盾的论证；
- **可解释**：输出人类可读的推理轨迹，且无手工管线开销。

### 数据集
- 真实世界的**主页（homepage）交互日志**。

## 深度分析

### 研究价值
- **理论贡献**：提出"双向合理化"这一可复现的失败模式，深化了对 LLM-as-judge 可靠性的理解。
- **实际应用**：为推荐系统离线评估提供了一条"LLM 替代特征管线"的可落地方案，显著降低维护成本。
- **领域影响**：展示了"从 prompting 到 behavioral alignment"的路径，对其他用 LLM 做主观/行为判断的任务有借鉴意义。

### 优势
1. 问题定位精准（双向合理化），并给出可复现的证据。
2. 方法简单有效：微调 + 偏好优化，无复杂架构改动。
3. 结果兼顾性能（匹配生产基线）与可解释性。

### 局限性
1. 主要验证在单一推荐场景（主页交互日志），跨场景泛化待验证。
2. "双向合理化"的深层原因（是模型校准问题还是训练数据偏差）未完全剖析。
3. 偏好优化依赖成对"正确/反事实"数据的构造质量。

### 适用场景
- 推荐系统离线评估、用户行为预测；
- 需要可解释判断 + 低维护成本的 LLM-as-judge 场景；
- 其它"用 LLM 替代手工特征/规则"的任务。

## 与相关论文对比

3. 探索更强/更轻量的偏好优化策略，进一步降低对齐成本。
