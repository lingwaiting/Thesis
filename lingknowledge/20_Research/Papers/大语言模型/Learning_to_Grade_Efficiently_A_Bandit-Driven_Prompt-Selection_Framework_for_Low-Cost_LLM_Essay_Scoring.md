## 摘要翻译

### 中文翻译
大语言模型在自动化作文评分（AES）上表现出色，但主流方法采用**固定的提示词选择**，忽略了运营成本与动态变化的最优配置。本文提出一种**成本感知**的方法，把每种提示词类型视作多臂老虎机（MAB）控制器中的一个"臂"，从而在推理过程中自适应地选择最优提示策略。在 IELTS 写作 Task 2 作文上的实验表明，MAB 框架在达到与穷举网格搜索相当的评分准确度的同时，把寻找最优评分方案所需的 LLM 调用次数降低了 **78.4%**。作者实现了四种评分配方（多步 vs. 单步评估、带 vs. 不带校准样例），发现带样例的多步方法准确度最高。通过同时追踪 token 用量、延迟与一致性指标，本文产出了**首条作文评分的"成本-可靠性"学习曲线**，为必须在运营成本与评估效度之间权衡的教育技术平台提供了可操作洞见。这项工作首次将在线控制机制应用于 AES 中的自适应提示策略选择，把提示词选择从离线超参数优化问题转化为高效的在线学习任务。

### 核心要点提炼
- **研究背景**：LLM 作文评分已成熟，但提示词选择仍是静态的、离线的，忽视成本。
- **研究动机**：教育平台需要在评分准确性与推理成本之间做动态权衡。
- **核心方法**：把提示词类型建模为 MAB 的臂，在线自适应选择最优提示策略。
- **主要结果**：相比穷举网格搜索，达到相当准确度的同时 LLM 调用减少 78.4%；产出首条成本-可靠性学习曲线。
- **研究意义**：把提示词选择从离线超参优化转化为在线学习问题，是 LLM 成本优化方向的代表性工作。

## 研究背景与动机

### 领域现状
LLM 在 AES 上的表现已接近甚至超过人类评分员，但工业部署中，"选择哪种提示策略"通常是一次性离线决策（网格搜索或人工经验），一旦确定就不再调整。

### 现有方法的局限性
1. **固定提示选择**无法应对最优配置随数据分布、成本预算、模型版本变化的动态性。
2. **穷举网格搜索**成本高昂，需要大量 LLM 调用来试出最优配方。
3. 现有 AES 研究几乎只报告准确度，**忽略成本与可靠性之间的权衡**。

### 研究动机
作者希望把"提示词选择"变成一个**在线、成本感知**的学习问题，让系统在推理时持续地、自适应地选择最优提示策略，从而在保证评分质量的前提下显著降低运营成本。

## 研究问题

### 核心研究问题
如何在自动化作文评分中，以**在线、成本感知**的方式自适应地选择最优提示策略，从而在维持评分准确度的同时最小化 LLM 调用成本？

## 方法概述

### 核心思想
把每一种提示词"配方"（recipe）视作多臂老虎机的一个臂，利用 MAB 控制器在探索（exploration）与利用（exploitation）之间平衡，实时地把更多调用分配给当前表现更好的配方。

### 方法框架

#### 整体架构
方法由"配方设计"和"MAB 控制器"两层构成：先定义候选提示配方，再由 MAB 控制器在线选择。

![[overall_comparison_totalestimatedcost.png|600]]

> 图1：整体成本对比图，展示 MAB 框架相对穷举搜索的成本优势。

#### 各模块详细说明

**模块1：配方设计**
- **功能**：定义候选提示策略。
- **输出**：四种评分配方。
- **关键技术**：两个维度的正交组合——（多步 vs. 单步评估）×（带 vs. 不带校准样例）。
- **关键发现**：带样例的多步方法准确度最高。

**模块2：MAB 控制器**
- **功能**：在线选择最优提示配方。
- **输入**：各配方的历史评分表现与成本。
- **输出**：每道作文应使用的提示策略。
- **处理流程**：
  1. 每个配方初始化为一个臂。
  2. 每次评分时，MAB 控制器根据历史奖励（准确度 + 成本）选择臂。
  3. 持续追踪 token 用量、延迟与一致性指标，更新臂的估计。
- **关键技术**：多臂老虎机（Multi-Armed Bandit）。

### 关键创新
1. **MAB 驱动提示选择** - 首次把在线控制机制引入 AES 提示选择，将离线超参优化转为在线学习。
2. **成本-可靠性学习曲线** - 同时追踪 token、延迟与一致性，产出首条 AES 成本-可靠性曲线。
3. **78.4% 调用削减** - 以远低于穷举搜索的成本达到相当的准确度，实用价值显著。

## 实验结果

### 数据集
- **IELTS Writing Task 2**：国际英语语言测试系统写作任务二作文集。

### 实验设置
- **配方**：多步/单步 × 带/不带校准样例，共四种。
- **对比基线**：穷举网格搜索（exhaustive grid search）。
- **评估指标**：评分准确度（QWK 等一致性指标）、LLM 调用次数、token 用量、延迟。

## 深度分析

### 研究价值
- **理论贡献**：将 AES 提示选择形式化为在线学习问题，架起了 LLM 推理优化与 bandit 算法的桥梁。
- **实际应用**：对教育科技平台极具价值，直接降低运营成本。
- **领域影响**：为"成本感知的 LLM 推理"这一新兴方向提供了可复用的范式。

### 优势
1. 问题定位清晰，成本-可靠性权衡是工业落地的真实痛点。
2. 实验设计干净（2×2 配方正交），消融逻辑清晰。
3. 结果直观且有说服力（78.4% 调用削减）。

### 局限性
1. 仅在一个任务（IELTS 作文评分）上验证，泛化到其他评分/生成任务待考。
2. MAB 的臂空间（4 个配方）较小，大规模臂空间下的扩展性未讨论。
3. 准确度对比对象是"穷举网格搜索"，与更先进的离线优化方法（如贝叶斯优化）的对比缺失。

### 适用场景
- 需要批量、低成本 LLM 评分的教育技术平台。
- 任何需要在推理时动态选择提示/配置以控成本的下游任务。

## 与相关论文对比
- **与传统 AES 研究**：本文从"追求最高准确度"转向"准确度-成本权衡"。
- **与 LLM 成本优化工作**（如 caching、early-exit、routing）：本文用 bandit 在线选择提示，与模型路由（routing）思路互补。

## 技术路线定位
本文属于 **LLM 推理成本优化** 路线，具体聚焦 **成本感知的提示词在线选择**，是把经典 bandit 算法应用于 LLM 应用层的代表工作。

## 未来工作建议
1. 扩展到更多评分任务与更多提示配方（更大的臂空间）。
2. 与贝叶斯优化、上下文 bandit（contextual bandit）结合，利用作文特征做更精细的选择。
3. 探索把 token 成本直接纳入奖励函数的更紧耦合设计。
