## 摘要翻译

### 英文摘要
We propose ScaleQ-1.58, a scalable ternary post-training quantization (PTQ) framework for reasoning LLMs. Its core insight stems from an empirical finding: although modern LLMs are typically trained to exhibit chain-of-thought reasoning capabilities, in the PTQ regime, even the latest CAT-Q method based on learning-based differentiable ternarization still leads to performance collapse on challenging mathematics and coding tasks when using conventional calibration schemes that ignore the model's reasoning process. Driven by this finding, we introduce a simple calibration approach, Attend to Your Own Thoughts (AYOT), where reasoning traces and final answers generated by the pre-trained high-precision target LLM on a proper set of calibration samples are used as the context input during the ternarization process, along with the corresponding questions. ScaleQ-1.58 is formed by simply integrating AYOT with CAT-Q, which demonstrates several scaling properties...

### 中文翻译
我们提出 ScaleQ-1.58，一个面向推理型 LLM 的可扩展三值后训练量化（PTQ）框架。其核心洞察源于一个实证发现：尽管现代 LLM 通常被训练以展现出思维链推理能力，但在 PTQ 场景下，即使最新的基于可学习可微三值化的 CAT-Q 方法，当使用忽略模型推理过程的传统校准方案时，仍会在挑战性数学和编程任务上导致性能崩溃。基于此发现，我们引入了一种简单的校准方法 AYOT（Attend to Your Own Thoughts），将预训练高精度目标 LLM 在适当校准样本集上生成的推理痕迹和最终答案与对应问题一起作为三值化过程中的上下文输入。ScaleQ-1.58 通过简单地将 AYOT 与 CAT-Q 集成而形成，展现出多项扩展特性...

### 核心要点提炼
- **研究背景**：推理型 LLM 部署面临巨大计算和内存开销，量化是关键解决方案
- **研究动机**：现有 PTQ 方法在量化推理型 LLM 时性能崩溃，因为忽略了模型的推理过程
- **核心方法**：AYOT 校准策略——用模型自身生成的推理痕迹作为量化校准的上下文输入
- **主要结果**：仅 4M token 实现高质量三值量化，Qwen3-4B 获 8.97% 绝对增益，标定成本降 100 万倍
- **研究意义**：首次突破 1.58-bit 推理型 LLM 量化的性能瓶颈，支持 MoE 架构

## 研究背景与动机

### 领域现状
推理型 LLM（如 DeepSeek-R1、Qwen3 等）通过链式思考（Chain-of-Thought）在数学、编程、科学推理等复杂任务上取得了突破性进展。然而，这些模型的部署面临巨大的计算和内存开销。后训练量化（PTQ）是降低部署成本的关键技术，1.58-bit（三值）量化因 BitNet b1.58 的成功而受到广泛关注。

### 现有方法的局限性
- **推理过程被忽略**：传统 PTQ 校准方案仅使用问题和标准答案，忽略了模型特有的推理生成过程
- **三值量化性能崩溃**：即使最新的 CAT-Q 方法，在推理型 LLM 上量化后性能严重退化
- **校准数据需求巨大**：BitNet b1.58 需要海量预训练 token，无法用于后训练场景

### 研究动机
推理型 LLM 的核心价值在于其推理能力，而现有 PTQ 方法在量化过程中"无视"了这一核心能力，导致量化后的模型丧失推理能力。因此，需要一种能"理解"并"保留"推理能力的量化方法。

## 研究问题

如何在后训练三值量化中保留推理型 LLM 的链式思考推理能力？

## 方法概述

### 核心思想
**让模型在量化校准过程中"关注自己的思考"**——将模型自身生成的完整推理痕迹和最终答案作为量化校准的上下文，使得量化过程能够感知并保留模型的推理行为模式。

#### 各模块详细说明

**模块1：AYOT 校准数据生成**
- **功能**：生成包含推理痕迹的校准数据集
- **输入**：校准问题集
- **输出**：（问题, 推理痕迹, 最终答案）三元组
- **处理流程**：
  1. 使用预训练的高精度 LLM 对校准问题进行推理
  2. 记录完整的 CoT 推理痕迹
  3. 提取最终答案
  4. 构建（Q, CoT, A）格式的校准样本
- **关键技术**：利用模型自身的推理能力生成高质量校准数据

**模块2：推理感知三值化（Reasoning-Aware Ternarization）**
- **功能**：在校准过程中将推理痕迹作为上下文输入
- **处理流程**：
  1. 将问题与推理痕迹拼接作为校准输入
  2. 通过可微三值化（CAT-Q）优化量化参数
  3. 使量化过程感知推理行为模式
- **关键技术**：CAT-Q 的可微三值化 + AYOT 校准策略

**模块3：ScaleQ-1.58 量化框架**
- **功能**：集成 AYOT 与 CAT-Q 的完整三值量化方案
- **扩展特性**：
  - 支持密集和 MoE 架构
  - 性能随模型规模提升（最高 235B）
  - 跨任务泛化（数学、编程、科学推理、常识推理、语言生成）

## 深度分析

### 研究价值评估

#### 理论贡献
- **推理感知量化范式**：首次提出将模型推理过程纳入量化校准的理论框架
  - 创新点：AYOT 校准策略概念简单但效果显著
  - 学术价值：为推理型模型的压缩提供了新视角
  - 影响范围：模型量化、推理型 LLM、高效部署

#### 实际应用价值
- **边缘部署**：使推理型 LLM 的 1.58-bit 部署成为可能，大幅降低内存和计算需求
- **成本降低**：标定 token 需求从海量降至 4M，极大降低量化成本
- **广泛兼容**：支持密集和 MoE 等多种架构，适用范围广

### 方法优势详解

#### 优势1：概念简单、效果显著
- **描述**：AYOT 仅改变校准数据的构造方式，无需修改量化算法本身
- **技术基础**：利用模型自身的推理能力作为校准信号
- **对比分析**：相比 BitNet b1.58 需要从头预训练，ScaleQ-1.58 仅需后训练

#### 优势2：极强的扩展性
- **描述**：从 1.7B 到 235B，从密集到 MoE，ScaleQ-1.58 均表现良好
- **实验验证**：在多种规模和架构上进行了全面验证

#### 优势3：通用性强
- **描述**：AYOT 在其他量化位宽上也表现出强泛化能力

### 局限性分析

#### 局限1：校准数据依赖推理质量
- **描述**：AYOT 依赖模型自身生成的推理痕迹质量
- **影响**：如果模型在某些领域的推理能力较弱，校准效果可能受限

#### 局限2：未覆盖训练后量化与 QAT 的对比
- **描述**：主要与 PTQ 方法对比，与量化感知训练（QAT）的对比有限

#### 局限3：实际推理速度待验证
- **描述**：三值量化在现有硬件上的实际推理加速效果需要进一步验证
