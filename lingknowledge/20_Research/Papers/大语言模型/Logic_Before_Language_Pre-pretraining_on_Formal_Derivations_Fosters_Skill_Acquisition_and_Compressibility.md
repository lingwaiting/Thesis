# Logic Before Language: Pre-pretraining on Formal Derivations Fosters Skill Acquisition and Compressibility

## 核心信息
- **论文ID**：arXiv:2608.03930
- **作者**：Jo-Ku Cheng, Nikolaos Aletras, Marco Valentino
- **机构**：University of Sheffield, UK
- **发布时间**：2026-08-04
- **链接**：[arXiv](http://arxiv.org/abs/2608.03930) | [PDF](https://arxiv.org/pdf/2608.03930)

## 摘要翻译

### 中文翻译
在符号数据上对语言模型进行"预-预训练"可以加速和改善自然语言获取。然而，现有的预-预训练任务（如 Dyck 语言和过程性算法）依赖过于狭窄的原语，无法捕捉自然语言的表达能力。此外，先前研究受限于较小的 token 预算，对技能涌现和表示动力学的洞察有限。为此，我们提出逻辑预-预训练 (Logic-PPT) 作为一种有原则的初始化策略，利用形式推导赋予模型更丰富的结构和语言偏置。形式推导需要自然语言中核心的抽象机制——同时绑定变量、连接量词和关系依赖、在长上下文中组合谓词-论元结构。在 100B token 规模下，Logic-PPT 显著加速了语言模型的技能获取，在语言任务上达到 80% 准确率，比标准初始化少用 36B token，并优于其他预-预训练基线。机制上，形式推导诱导了持续的结构重组，呈现更低秩、频谱更集中的表示空间。关键的是，这种内部几何结构实现了更好的模型可压缩性，在约 33% 稀疏度下仍能匹配密集基线性能。

### 核心要点提炼
- **研究背景**：预-预训练（pre-pretraining）已被证明可以加速语言获取，但现有方法表达力不足
- **研究动机**：需要一种更具表达力的符号初始化策略来模拟自然语言的结构复杂性
- **核心方法**：在语言预训练前使用形式推导数据进行逻辑预-预训练 (Logic-PPT)
- **主要结果**：达到 80% 准确率节省 36B token；低秩表示空间；33% 稀疏度下保持密集基线性能
- **研究意义**：首次在大规模 token 预算下证明逻辑先验对 LLM 训练效率和可压缩性的双重价值

## 研究背景与动机

### 领域现状
预-预训练已被证明可通过在符号数据（如 Dyck 语言、过程性算法）上先训练来加速语言学习。但这些任务表达力有限，且先前工作限于小 token 预算。

### 现有方法的局限性
- Dyck 语言和过程性算法仅涉及狭窄的语法原语，无法捕捉自然语言的语义丰富性
- 小规模实验无法揭示技能涌现和表示动力学的真实规律
- 缺乏对预-预训练如何影响模型内部几何结构和可压缩性的理解

### 研究动机
形式推导（formal derivations）需要变量绑定、量词连接、关系依赖追踪和谓词-论元结构组合——这些恰是自然语言理解所需的核心抽象机制。如果让模型先在形式逻辑中学习这些机制，是否能更好地为自然语言学习做好准备？

## 方法概述

### 核心思想
在标准语言预训练之前插入一个逻辑预-预训练阶段，让模型先学习形式推导的抽象推理机制，再将这些结构化偏置迁移到自然语言任务中。

### 方法框架

> 图1：Logic-PPT 三个核心发现：(A) 更快学习——节省 36B token 达到同等准确率；(B) 更低秩表示——表示空间更紧凑和结构化；(C) 更强压缩鲁棒性——33% 稀疏度下保持密集基线性能。

#### 逻辑预-预训练 (Logic-PPT)
- **数据**：形式推导（formal derivations），包含逻辑规则、量词操作、变量绑定和谓词-论元结构
- **训练阶段**：Logic-PPT → 标准语言预训练（100B token 规模）
- **对比基线**：标准预训练（无预-预训练）、Dyck 语言预-预训练、过程性算法预-预训练

## 实验结果

### 主要结果

#### 技能获取加速
- Logic-PPT 达到 80% 平均准确率比标准 PT 基线节省 36B 自然语言训练 token
- 在 100B token 规模下的语言任务上全面优于其他预-预训练基线

#### 表示空间结构重组
- Logic-PPT 诱导出更低的稳定秩（stable rank）和更集中的频谱衰减
- 跨层 CKA 分析显示结构重组是全局性的，贯穿所有层
- 表示空间围绕更少的方向组织——更紧凑、更具可解释性

#### 模型可压缩性提升
- 在约 33% 稀疏度下，Logic-PPT 模型保持密集 PT 基线的准确率
- Wanda 剪枝实验验证了低秩表示结构直接转化为更强的压缩鲁棒性
- 这一特性对实际部署（低资源、边缘设备）具有重要价值

### 机制分析
- 形式推导中的变量绑定和量词连接机制内化为模型的内部偏置
- 低秩结构表明模型学到了更本质、更可压缩的知识组织方式
- 这种"先学逻辑再学语言"的范式类似于人类认知发展中逻辑推理先于语言习得的假说

## 深度分析

### 研究价值评估

#### 理论贡献
- **大规模验证逻辑先验价值**：首次在 100B token 规模下证明形式逻辑预训练对语言学习的促进作用
- **揭示表示几何与可压缩性的关联**：低秩表示 → 更好的可压缩性，这一发现具有基础研究价值
- **连接符号推理与神经网络学习**：为混合符号-神经架构提供了新的实证支撑

#### 实际应用价值
- 训练效率：节省数十亿 token 的训练成本
- 模型压缩：天然支持高稀疏度剪枝，降低部署成本
- 小模型场景：对资源受限环境下的高质量语言模型训练有直接指导意义

### 局限性分析
1. **对形式推导数据规模和质量的依赖**：大规模高质量形式推导数据的获取可能成为瓶颈
2. **仅验证了英语任务**：多语言场景下的迁移效果未知
3. **100B token 仍非最大规模**：在更大规模（1T+）下的效果和衰减趋势未知
4. **逻辑形式的覆盖度**：当前形式推导覆盖的逻辑类型可能不全面
