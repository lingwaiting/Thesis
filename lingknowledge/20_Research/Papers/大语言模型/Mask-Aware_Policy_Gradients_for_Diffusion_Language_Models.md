## 摘要翻译

### 中文翻译
强化学习已被证明能有效改善大语言模型的推理能力，但将其扩展到掩码扩散语言模型（MDLM）仍具挑战性，因为对数似然估计的不可解性。现有方法仅建模 token 预测来近似此对数似然，忽略了生成过程中位置被去掩码的顺序。我们观察到 MDLM 生成在每一步涉及两个决策：在每个掩码位置放置什么 token，以及哪些位置重新掩码。我们将此形式化为两阶段动作 MDP，表明策略梯度自然分解为 token 项和 masking 项。联合优化两项在数学推理基准 GSM8K 上达到 87.1%，在代码基准 MBPP 上达到 53.4%，均为 SOTA。

## 研究背景与动机

### 领域现状
扩散语言模型（DLM）作为自回归语言模型的替代方案正在兴起。与逐 token 生成不同，DLM 通过迭代去噪生成文本，具有双向上下文、可并行解码等优势。然而，将 RL 应用于 DLM 仍是一个开放问题。

### 现有方法的局限性
- **对数似然不可解**：MDLM 的生成过程涉及多步掩码-去掩码，精确的对数似然无法计算
- **仅建模 token 预测**：现有方法忽略 masking 策略的优化，仅关注"预测什么 token"
- **次优性能**：忽略 masking 顺序导致策略梯度估计不完整

### 研究动机
如何将 RL（特别是策略梯度）正确且有效地应用于 MDLM，使其在推理任务上达到或超越自回归模型的水平？

## 方法概述

### 核心方法

**1. 两阶段动作 MDP 形式化**
- 将 MDLM 每步生成分解为两个子决策：
  - Token 决策：在每个掩码位置预测什么 token
  - Mask 决策：哪些位置将被重新掩码
- 形式化为两阶段动作马尔可夫决策过程

**2. 策略梯度分解**
- Token 梯度项：优化 token 预测质量
- Masking 梯度项：优化去掩码顺序
- 两项自然从 MDP 结构中导出，无需近似

**3. 联合优化**
- 同时优化两个梯度项
- 无需对数似然近似、无需 critic 网络
- 直接使用策略梯度方法（如 REINFORCE/PPO）

### 关键创新
- **首次揭示 MDLM 生成的双决策本质** — 之前的工作忽视了 masking 策略的重要性

- **统一优化框架** — 同时优化 token 和 mask 策略，无需额外超参数

## 深度分析

### 研究价值
- **理论贡献**：首次为 MDLM 的 RL 训练提供正确的策略梯度推导
- **实际应用**：使扩散语言模型在推理任务上媲美甚至超越自回归模型
- **领域影响**：为扩散模型 + RL 的交叉研究奠定了基础框架

### 优势
- 数学推导严谨，从 MDP 结构自然导出策略梯度
- 方法简洁，无需额外网络（critic、奖励模型等）
- 实验结果清晰，消融实验充分
- UT Austin 团队，代码开源可能性高

### 局限性
- 仅在数学推理（GSM8K）和代码生成（MBPP）上验证
- MDLM 本身仍是较新的范式，生态不如自回归模型成熟
- 两阶段 MDP 是否适用于所有 MDLM 变体待验证
- 长文本生成场景下的有效性尚未探索

### 适用场景
- 需要强化学习微调的扩散语言模型
- 数学推理和代码生成等有明确奖励信号的任务
- 需要非自回归生成（双向上下文、可控生成）的场景

## 技术路线定位

本文属于**扩散语言模型 × 强化学习**交叉方向，是首批将策略梯度正确应用于 MDLM 的工作。它填补了自回归模型 RLHF/GRPO 成功与扩散模型 RL 训练之间的方法论空白。

## 未来工作建议

1. 扩展到更大规模模型和更多推理基准
2. 与 GRPO/PPO 等现代 RL 算法的结合
3. 在多模态扩散模型中应用两阶段策略梯度
4. 探索 masking 策略的可解释性
