## 摘要翻译

### 中文翻译

银行会分析**顺序金融交易数据**来完成众多任务，包括欺诈防范、信用风险评估和优惠个性化。为了提升这些任务的预测准确率，**支付基础模型（Payments Foundation Models）**将交易序列数据编码为丰富的上下文嵌入，再提供给任务专用模型作为特征。然而，这些基础模型并非为面向新颖下游预测任务的**灵活零样本推理**而设计，限制了其适应性与实用性。现有基于 LLM 的零样本预测方法往往无法充分利用交易数据中的预测信号，同时依赖昂贵的文本序列化或难以扩展的任务专用架构。针对这些局限，作者提出 **MINT（Multimodal Instruction Network for Transactions）**，一个将预训练的交易序列编码器通过**轻量嵌入注入、交易-语言对齐和指令微调**连接到 decoder-only LLM 的框架。研究发现，MINT 在分布内（ID）和分布外（OOD）问题上均取得**最先进的预测问答性能**，同时相比文本序列化基线显著降低输入 token、延迟与内存占用。通过对表征、对齐策略、训练数据和历史长度的综合分析，作者确立：**紧凑的交易嵌入是比文本序列化更优的交易表征方式**，适用于多模态推理与零样本预测任务。

### 核心要点提炼
- **研究背景**：银行用交易序列数据做欺诈、风控、个性化等预测；支付基础模型编码交易但缺乏零样本推理。
- **研究动机**：现有 LLM 零样本预测依赖文本序列化，token 昂贵、且未能充分利用交易信号。
- **核心方法**：MINT 用轻量嵌入注入 + 交易-语言对齐 + 指令微调，连接交易编码器与 decoder-only LLM。
- **主要结果**：ID/OOD 预测 QA 均 SOTA，同时大幅降低 token、延迟与内存。
- **研究意义**：确立"紧凑交易嵌入优于文本序列化"的结论，为金融多模态推理提供新范式。

## 研究背景与动机

### 领域现状
支付与金融领域大量使用**时序交易数据**做下游预测（欺诈检测、信用评分、个性化推荐）。近年兴起的"支付基础模型"（Payments Foundation Models）能把交易序列编码成语义化嵌入，供下游任务使用，但它们是**编码器**，不具备面向开放问题的零样本推理能力。

### 现有方法的局限性
- **文本序列化昂贵**：把交易序列转成文本再喂给 LLM，token 爆炸、延迟高、内存大。
- **信号利用不充分**：文本序列化丢失交易数据的结构化预测信号。
- **任务专用架构难扩展**：为每个新预测任务单独设计模型，扩展性差。

### 研究动机
需要一种把**交易序列编码器**与**通用 LLM**结合的方式，既能保留交易嵌入的紧凑与信息量，又能获得 LLM 的零样本推理能力。

## 研究问题

### 核心研究问题
1. 如何连接预训练交易序列编码器与 decoder-only LLM，实现零样本预测问答？
2. 如何在不依赖昂贵文本序列化的前提下，充分利用交易数据中的预测信号？
3. 紧凑的交易嵌入是否比文本序列化更适合作为多模态推理的交易表征？

## 方法概述

### 核心思想
MINT 通过一个**轻量适配层**把交易序列编码器产生的紧凑嵌入注入 LLM，配合**交易-语言对齐**与**指令微调**，让 LLM 能直接"读懂"交易嵌入并回答预测问题，从而兼顾信息量、效率与零样本泛化。

### 方法框架

#### 整体架构
![[mint_fig1_overview.png|700]]

> 图1：MINT 总览。交易历史经预训练交易序列编码器得到紧凑嵌入，通过轻量嵌入注入接入 decoder-only LLM，再经交易-语言对齐与指令微调实现零样本预测问答。

#### 各模块详细说明

**模块1：预训练交易序列编码器**
- **功能**：将顺序交易数据编码为紧凑的上下文嵌入。
- **输入**：交易历史序列（金额、商户、时间戳等）。
- **输出**：高信息密度的交易表征向量。
- **关键技术**：复用预训练编码器，避免重复处理海量交易数据。

**模块2：轻量嵌入注入（Embedding Injection）**
- **功能**：将交易嵌入通过轻量适配层注入 LLM 的输入空间，而非文本序列化。
- **输入**：交易嵌入。
- **输出**：LLM 可接受的嵌入 token。
- **关键技术**：轻量投影层，训练成本低、token 数大幅减少。

**模块3：交易-语言对齐 + 指令微调**
- **功能**：让 LLM 理解交易嵌入与自然语言问题的对应关系，并遵循预测指令。
- **输入**：对齐后的交易嵌入 + 自然语言指令。
- **输出**：预测答案。
- **关键技术**：对齐（alignment）使交易表征进入 LLM 的语义空间；指令微调（instruction tuning）赋予其零样本问答能力。

### 关键创新
- 用**紧凑嵌入注入替代文本序列化**，大幅降低 token、延迟与内存。
- 连接交易编码器与通用 LLM，获得**零样本预测问答**能力。
- 通过系统的表征/对齐/数据/历史长度分析，**实证确立**"嵌入优于文本序列化"。

## 实验结果

### 主要结果
- **预测 QA SOTA**：在 ID 与 OOD 问题上均取得最先进的预测问答性能。
- **效率大幅提升**：相比文本序列化基线，显著降低输入 token、延迟与内存占用。

![[mint_fig2_tradeoff.png|700]]

### 消融与综合分析
- 对**表征方式、对齐策略、训练数据、历史长度**进行系统分析。
- 结论：**紧凑交易嵌入**是比文本序列化更优的交易表征方式，用于多模态推理与零样本预测。

## 深度分析

### 研究价值评估

#### 理论贡献
- **嵌入注入 vs 文本序列化的实证结论**：为"如何把结构化时序数据接入 LLM"提供了一个有说服力的范式选择依据。
- **交易-语言对齐**：将多模态对齐思想迁移到金融交易域。

#### 实际应用价值
- **金融场景落地**：欺诈、风控、个性化推荐等预测任务可直接受益，token 与延迟的降低对实时场景尤其重要。
- **通用性**：方法不仅限于交易，可推广到任意结构化时序数据 + LLM 的结合。

### 局限性分析
- **依赖预训练编码器**：性能受上游交易编码器质量制约。
- **隐私合规**：金融交易数据接入 LLM 需处理数据隐私与合规问题。

### 适用性与场景分析
- **适用场景**：银行/支付机构的欺诈检测、信用评分、个性化推荐等零样本预测任务。
- **不适用场景**：对可解释性要求极高、需逐字段解释预测依据的强监管场景。

## 与相关论文对比

### 与文本序列化 LLM 预测方法的关系
- 传统方法（如将交易记录序列化为文本再微调 LLM）token 昂贵、信号利用不充分。
- MINT 用嵌入注入替代，在效率与准确率上同时占优，是更优的结构化数据接入范式。
