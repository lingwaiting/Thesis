## 摘要翻译

### 中文翻译
大语言模型如今能通过修订自己遵循的指令来自我改进，LLM 智能体也越来越多地被编排以协作解决复杂问题。然而，自我改进方法通常一次只优化单个系统，多智能体框架又常让所有模型朝同一共享目标努力。本文问了一个不同的问题：**当每个智能体追求各自奖励时，自我改进的 LLM 能否通过互相学习，好到足以提升整个种群？** 作者将这种能力称为 **recursive social improvement（递归社会改进）**。他们研究了会修订 skill 文件、并自主选择是否/何时/向谁复制的种群，其中独立搜索、向同伴学习和行动三者共享同一 token 预算。在受控环境中，成熟的社会学习算法能从同伴获益，但三个 LLM 都不能：它们每 token 获得的奖励低于独立学习者，且探索过窄或在行动前耗尽 token。随后让模型自己编写并修订 skill，观察同伴会改变它们的改进方式——帮助一个模型更早找到有用 skill、另一个减少私有搜索开销，但两者都未能在相同成本下超过独立学习者。skill 被复制、修订、传递，一个发现可以播种后续搜索，但这些交换把种群集中在更少的独立发现周围。综上，结果表明 LLM 能通过复制同伴提高学习效率，但尚未能提高学习效果。

### 核心要点提炼
- **研究背景**：LLM 自我改进与多智能体协作兴起，但"自利智能体互相学习"的能力未被刻画。
- **研究动机**：自我改进常单系统优化，多智能体常共享目标，缺少"各自追求奖励时互相学习"的研究。
- **核心方法**：受控 bandit 环境 + 递归社会改进框架（复制/修订 skill、共享 token 预算）。
- **主要结果**：社会学习算法受益但三个 LLM 均未受益，每 token 奖励下降 30–52%；复制能提效但未提效效果。
- **研究意义**：首次系统刻画 LLM 的"递归社会改进"，揭示其能提效但不能提质的关键发现。

## 研究背景与动机

### 领域现状
LLM 现已成为编码助手等自动化系统的核心推理组件，其性能不仅取决于权重，还取决于所遵循的指令与流程（如 skill 文件）。skill 文件是推理时提供的文本，可在不改变模型的情况下被修订、复制与共享。现有改进方法（prompt 优化、反思、进化搜索）通常聚焦单一系统。

### 现有方法的局限性
1. **单系统优化**：自我改进方法一次只优化一个系统，未利用同伴的发现。
2. **共享目标假设**：多智能体框架常让所有模型朝同一目标努力，回避了"自利智能体是否互相学习"的根本问题。
3. **探索-利用困境被忽视**：每次尝试消耗 token 且只给出价值的有噪声估计，系统面临"搜索更好流程 vs 使用当前最优"的权衡。

### 研究动机
智能体已经能从 GitHub 下载其他智能体使用的 skill 与脚手架（gavrielc et al., 2026），OpenAI 也曾协调约 1 万个智能体解决 Navier–Stokes 问题。但这些 swarm 工作都在解决单一任务。本文问：当许多自利 LLM 智能体各自优化自己的任务、但能看到同伴产出时，会发生什么？这触及行为生态学、文化演化与经济学中长期研究的张力——向他人学习有价值的前提是有人独立搜索，而每个个体都希望别人承担搜索成本。

## 研究问题

### 核心研究问题
当每个自利智能体追求自己的奖励、且在"独立搜索 / 向同伴学习 / 行动"之间共享一个 token 预算时，自我改进的 LLM 能否通过互相学习提升整个种群？（能否从同伴学习中获得效率或效果优势？）

## 方法概述

### 核心思想
将"递归社会改进"建模为：智能体在每轮中决定是"修订自己的 skill"、"复制同伴的 skill"、还是"跳过学习"，然后用选中的 skill 解决任务并获得反馈，整个流程共享一个有限 token 预算。作者在受控的 25-臂 bandit 环境中，对比独立（solo）与社会（social）种群的奖励/token 效率。

### 方法框架

#### 整体架构

![[recursive_social_improvement_overview_page1.png|700]]

> 图1：递归社会改进框架。一个智能体可以复制同伴的 skill 文件、修订自己的 skill、或跳过学习；复制与修订为其可复用任务指令库增添备选。随后它选择任一已保存的 skill（含早期版本）用于解决任务，反馈指导下一轮。整个过程共享一个有限 token 预算，同伴独立遵循同样循环、各自追求自己的任务奖励。

#### 各模块详细说明

**模块1：受控 Bandit 环境**
- **功能**：提供可精确度量社会学习价值的实验平台。
- **设计**：适配 Rendell et al. (2010) 的社会学习锦标赛——25 臂 bandit、固定均值收益、噪声奖励，10 个智能体运行 100 轮，8 个环境种子。
- **对照**：用算法基线（solo UCB、hierarchical social UCB）验证环境本身是否奖励社会学习。

**模块2：递归社会改进循环**
- **功能**：刻画自利智能体的学习决策。
- **流程**：每轮智能体在"复制同伴 / 修订自己的 skill / 跳过学习"之间选择 → 从自己的 skill 库选择 skill（含早期版本）→ 用 skill 解决任务 → 获得反馈 → 下一轮依据反馈再选择。
- **关键约束**：独立搜索、向同伴学习、行动三者共享同一 token 预算，每次复制/修订都计入成本。

**模块3：三个 LLM 的评测**
- **模型**：Qwen3-14B、Ministral-3-14B-Reasoning-2512、GPT-OSS-20B。
- **对比维度**：每 token 奖励、探索广度、行动前是否耗尽 token。

## 实验结果

### 实验目标
(1) 社会学习环境是否奖励向同伴学习（算法基线验证）；(2) LLM 是否能在该环境中从同伴获益；(3) 当模型自写并修订 skill 时，观察同伴是否改变其改进方式。

### 数据集与基线
- **环境**：25 臂 bandit，固定均值收益 + 噪声奖励，10 智能体 × 100 轮，8 环境种子。
- **模型**：Qwen3-14B、Ministral-3-14B-Reasoning-2512、GPT-OSS-20B。
- **算法基线**：solo UCB、hierarchical social UCB（无 LLM 推理）。

### 主要结果
- **算法基线受益**：social UCB 明显优于 solo UCB（奖励提升主要来自同伴信息），验证环境本身奖励社会学习。
- **LLM 均未受益**：三个 LLM 观察同伴后每 token 奖励均下降——**Qwen 下降 29.6±13.4%、Ministral 下降 41.8±11.6%、GPT-OSS 下降 51.9±7.8%**（GPT-OSS 经校正后显著）。社会智能体每 token 奖励约为 solo 的 30–52% 更低。
- **探索过窄或耗尽 token**：LLM 社会种群要么探索过窄，要么在行动前耗尽 token。
- **复制能提效但不能提质**：观察同伴改变了改进方式——一个模型更早找到有用 skill、另一个减少私有搜索开销，但两者都未能在相同成本下超过独立学习者；GPT-OSS-120B 使用的学习 token 少三分之一（更高效），但匹配学习 token 后仍未超过 solo。

## 深度分析

### 研究价值评估

#### 理论贡献
- **贡献1：定义递归社会改进**——首次形式化"自利自我改进 LLM 种群能否互相学习提升整体"这一能力。
- **贡献2：受控环境的严谨刻画**——用算法基线分离"环境是否奖励社会学习"与"LLM 是否能实现社会学习"。
- **贡献3：反直觉的实证结论**——LLM 能提效但不能提质，探索-利用与社会学习间的张力被清晰量化。

#### 实际应用价值
- **应用场景1：多智能体系统设计**：提示当前 swarm/多智能体编排中"共享成果"并不自动带来收益，需重新设计复制与探索的权衡机制。
- **应用场景2：自我改进系统**：为 skill 共享、复制机制的实际部署提供"是否值得、何时值得"的实证依据。

### 方法优势详解

#### 优势1：问题定位精准
- **技术基础**：将行为生态学/文化演化的经典张力（社会学习的"搭便车"问题）移植到 LLM 语境。

#### 优势2：受控对照严谨
- **技术基础**：算法基线（solo/social UCB）与 LLM 的对照，排除了"环境本身不奖励社会学习"的混淆。

### 局限性分析

#### 局限1：环境规模有限
- **描述**：25 臂 bandit + 受控任务，与真实 skill 共享（如 GitHub 生态）的复杂性差距较大。
- **影响**：结论能否推广到开放任务、异构任务分布仍有待验证。

#### 局限2：结论偏"负向"
- **描述**：主要结论是"LLM 未受益"，正面指导（如何让社会学习有效）着墨较少。
- **影响**：对想直接应用社会学习的实践者而言，行动指南有限。

#### 局限3：模型的同质化
- **描述**：仅测三个模型，且均为指令遵循型，未覆盖更强的推理型/专用型模型组合。

## 技术路线定位

### 所属技术路线
本文属于 **多智能体 LLM + 自我改进（Self-Improvement）** 的交叉路线，与 swarm/多智能体协作、prompt 优化/进化搜索、文化演化计算（cultural evolution）相关。

### 本文在技术路线中的位置
- **承上**：承接单系统自我改进（prompt 优化、反思、进化搜索）与多智能体协作。
- **启下**：为"社会学习在 LLM 中的有效性"提供了负面基准，后续可研究如何设计复制策略、网络结构或激励使社会学习真正有效。
