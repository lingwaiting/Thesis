# WorldSample：基于世界模型的闭环真实机器人强化学习

## 研究问题与动机

### 核心问题

真实机器人强化学习面临"数据饥渴"困境：

1. **样本效率低**：物理机器人收集数据昂贵且耗时，一次 rollout 可能花费数分钟
2. **Sim-to-Real Gap**：纯仿真训练的模型迁移到真实世界时性能大幅下降
3. **世界模型缺乏闭环验证**：现有世界模型方法通常是"离线想象"，缺乏与真实物理世界的反馈循环

### 核心洞察

世界模型不应只是"想象"，而应嵌入到"物理 rollout → 想象增强 → 策略改进 → 物理验证"的闭环中。关键挑战是如何调控合成数据的质量和使用比例——太多低质量合成数据会误导策略。

---

## 方法概述

WorldSample 提出三环嵌套架构：

```
┌──────────────────────────────────────────────────┐
│              WorldSample 闭环架构                    │
├──────────────────────────────────────────────────┤
│                                                   │
│  物理 Rollout（真实机器人）                          │
│      │                                            │
│      ▼                                            │
│  世界模型生成（合成数据增强）                         │
│      │                                            │
│      ▼                                            │
│  策略改进（RL 训练，PPL 调控）                       │
│      │                                            │
│      └──────────→ 回到物理 Rollout ──→ 循环         │
│                                                   │
│  PPL: Policy-Paced Learning 动态调控               │
│  ├─ 策略弱时：多用简单合成数据                        │
│  └─ 策略强时：逐步引入困难合成数据                    │
│                                                   │
└──────────────────────────────────────────────────┘
```

### 核心组件 1：物理-合成闭环

1. **物理 Rollout**：在真实机器人上执行当前策略，收集真实数据
2. **世界模型生成**：基于物理数据训练/更新世界模型，生成合成 rollout
3. **策略改进**：在混合数据（真实 + 合成）上进行 RL 训练
4. **物理验证**：新策略在真实机器人上测试，验证改进效果，数据回流

### 核心组件 2：Policy-Paced Learning（PPL）

PPL 是 WorldSample 的核心创新——一种动态调控合成数据使用的课程学习机制：

- **策略能力评估**：持续跟踪当前策略在验证任务上的表现
- **难度匹配**：根据策略能力动态选择合成数据的难度级别
  - 策略较弱时：生成简单场景的合成数据，确保学习信号干净
  - 策略较强时：逐步引入困难/边缘场景，推动进一步改进
- **比例调控**：随着策略改进，逐步增加合成数据的比例（从低比例到平衡）

### 世界模型架构

- 基于物理先验的生成模型（具体架构类型需参考原文）
- 输入：物理 rollout 数据（状态-动作-下一状态）
- 输出：合成 rollout（多样化的场景变体）
- 增强策略：添加噪声、变换初始条件、引入扰动

## 关键创新

1. **闭环设计**：世界模型不是离线使用的，而是嵌入到物理-合成-策略的循环验证中
2. **Policy-Paced Learning（PPL）**：首次提出基于策略能力的自适应课程学习，解决合成数据"什么时候用、用多少、用多难"的核心问题
3. **物理先验注入**：世界模型利用物理约束（而非纯数据驱动），提高合成数据的物理合理性
4. **样本效率的突破性提升**：59% 减少训练步数意味着机器人训练时间可能从数周缩短到数天

## 实验与结果

### 任务

在**接触密集型操作任务**（contact-rich manipulation）上验证：
- 插拔、旋转、推拉等需要精确力控的任务
- 这类任务最需要真实世界数据，sim-to-real gap 最大

### 关键结果

| 指标 | 改进 |
|------|------|
| 策略成功率 | **+28%** |
| 训练步数 | **-59%** |
| PPL vs 固定比例合成 | 显著更优 |

### 消融实验

- **无世界模型** vs **有世界模型**：世界模型的合成数据是关键增益来源
- **固定比例合成** vs **PPL 自适应**：PPL 显著优于固定比例
- **开环世界模型** vs **闭环世界模型**：闭环设计避免了合成数据的分布漂移

## 深度分析

### 优势

1. **实际部署价值极高**：直接解决机器人学习中最痛的点——数据收集成本
2. **PPL 是通用方法**：Policy-Paced Learning 的思路可以推广到任何使用合成数据的 RL 设置
3. **闭环验证保证安全**：避免纯仿真训练的不可靠性
4. **从 NTU + 清华的联合团队**：中-新顶尖机器人/RL 团队的合作

### 局限

1. 世界模型本身的质量是瓶颈——如果世界模型在关键物理现象上不准确，会误导策略
2. 接触密集型任务的复杂性仍然很高，28% 提升后可能离实际部署还有距离
3. 仅在特定任务类型上验证，在其他形态（如移动操作、多机器人）上的效果未知
4. PPL 的难度度量方法可能需要针对不同任务定制

### 展望

- 世界模型 + 基础模型（如视觉-语言模型）的结合：利用预训练的世界知识增强物理世界模型
- PPL 可以迁移到其他"合成数据辅助训练"的场景（如自动驾驶、无人机导航）
- 从"减少训练步数"到"零样本迁移"是下一步目标
