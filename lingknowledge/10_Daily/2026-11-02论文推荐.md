## 今日概览

今日推荐的 10 篇论文主要聚焦于**具身智能的世界模型与记忆**、**多模态模型的推理与认知对齐**和**大模型效率与推理基础设施**三大前沿方向。

- **总体趋势**：本期呈现三条清晰主线——其一，具身智能从"直接策略学习"走向"世界模型 + 记忆"的底层机制（ID-WM 用隐式动力学分层世界模型降复合误差、具身记忆综述系统梳理记忆需求与架构、ORION 用结果驱动记忆闭环 LLM 规划器）；其二，多模态模型开始向"可扩展推理"与"认知对齐"要增量（LARC 把推理从离散 token 搬到连续隐空间以恢复 test-time scaling、Aligning MLLMs 用 470 万条人类判断对齐认知结构、DA-CoT 用注意力熵自适应触发思维链）；其三，LLM 的效率与推理基础设施继续从注意力架构（ZHA 亚二次注意力）与基础模型（Chronos-2 时序基础模型）两侧发力，同时智能体策略优化（TSBPO）与 LLM 符号回归的不确定性（LLM-SR-UQ）补齐方法链。
- **质量分布**：今日推荐论文评分在 8.37–10.4 之间，头部一篇（ORION）明显领跑，三篇 8.8–9.3 的高分论文紧随其后，整体质量较高且方向多元。
- **研究热点**：
  - **世界模型与记忆驱动的具身智能**：分层/隐式动力学世界模型、结果驱动的记忆闭环，共同指向"从局部控制到长期自适应"。
  - **连续/自适应推理的多模态**：连续空间潜在推理、注意力熵驱动的难度感知思维链，让多模态生成与理解获得 test-time scaling 与效率。
  - **认知对齐**：用大规模人类行为数据（O1O 判断）对齐模型表征与人类认知结构，并以 fMRI 表征相似性作为神经验证。
- **阅读建议**：建议优先精读评分最高的 ORION（结果驱动记忆闭环 LLM 规划）与前 3 篇；关注具身智能与世界模型可读第 4、5 篇；关注多模态推理与认知对齐可读第 2、3、9 篇；关注大模型效率与推理基础设施可读第 8、10 篇；关注智能体训练与符号回归不确定性可读第 6、7 篇。

### [[ORION_An_Outcome-Driven_LLM_Advisor_for_RL-Based_Multi-Domain_6G_Slice_Placement|ORION: Outcome-Driven LLM Advisor for 6G Slice Placement]]
- **作者**：Mahmoud S. Mayaleh, Fetia Bannour, Nour-El-Houda Yellas
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.41563) | [PDF](https://arxiv.org/pdf/2610.41563)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/强化学习与智能体/ORION_An_Outcome-Driven_LLM_Advisor_for_RL-Based_Multi-Domain_6G_Slice_Placement|ORION 详细分析]]

**一句话总结**：用"结果驱动情景记忆"让 LLM 规划器以部署可行性（而非自评标量奖励）闭环，跨域 6G 切片接纳率提升 4.6–11.5 个百分点。

![[2610.41563_fig1.png|600]]

**核心贡献/观点**：
- 定位"规划层"为跨域切片放置的决定性杠杆：多数被拒请求其实存在可行放置，只是未被发现
- 两个 LLM 智能体生成抽象放置规划，协作式多智能体 RL 协调器做跨域划分，域内智能体执行放置
- 结果驱动情景记忆记录「网络状态画像 + 所提规划 + 已验证可行性」，重要性保留策略回灌成功/失败标注

**关键结果**：在 held-out 拓扑族上（固定下游选择/执行机制），记忆使接纳率较无记忆规划器提升 4.6–11.5 pp，importance-based retention 贡献大部分增益。

### [[Latent_Reasoning_in_Continuous_Space_for_Unified_Multimodal_Models|LARC: Latent Reasoning in Continuous Space]]
- **作者**：Byungwoo Jeon, Yoonwoo Jeong, Hyunseok Lee, Minsu Cho, Jinwoo Shin
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.42149) | [PDF](https://arxiv.org/pdf/2610.42149)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/多模态/Latent_Reasoning_in_Continuous_Space_for_Unified_Multimodal_Models|LARC 详细分析]]

**一句话总结**：在连续隐空间做潜在推理，弥合"离散 token 推理 vs 连续图像生成"的模态错配，让文生图首次获得清晰的 test-time scaling。

![[2610.42149_fig1.png|600]]

**核心贡献/观点**：
- 定位 UMM 无法继承 test-time scaling 的根因：推理在离散 token 空间、生成在连续空间，存在模态错配
- 课程 SFT 把 token 级推理逐步蒸馏为潜在（latent）推理，信息增益 RL 在无真值监督下自演化
- 潜在推理天然支持并行/串行两种 test-time scaling，恢复细粒度可控性

**关键结果**：GenEval 上取得 SOTA（较 BAGEL 提升 7p），在并行与串行两种 test-time scaling 策略下均优于基于 token 的生成。

### [[Know_When_the_Equation_Is_Wrong_Structural_Uncertainty_for_LLM-Guided_Symbolic_Regression_under_Extrapolation|LLM-SR-UQ: Structural Uncertainty for Symbolic Regression]]
- **作者**：Mostafa Cham, Bayu Adhi Tama, Jianwu Wang
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.42024) | [PDF](https://arxiv.org/pdf/2610.42024)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：保留竞争方程结构、用其分歧刻画函数形式不确定性，把结构分歧纳入 conformal 区间，改善外推场景下的覆盖。

**核心贡献/观点**：
- 指出不同方程可同拟合观测数据却产生截然不同的外推，标准 conformal 区间外推时常失效
- 扩展固定宽度 conformal 到"结构区间"，度量候选方程之间的分歧以定位区间应放宽之处
- 方法可泛化应用到其他符号回归方法

**关键结果**：在保持分布内覆盖的同时，通过纳入结构分歧大幅改善外推覆盖达成率。

### [[Subquadratic_Attention_with_a_Hierarchical_Tree-Structured_Indexer|ZHA: Subquadratic Hierarchical Attention]]
