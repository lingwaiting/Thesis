## 今日概览

今日推荐的 10 篇论文主要聚焦于 **分子表征与科学基础模型**、**LLM Agent 记忆与知识管理** 和 **扩散语言模型与视频多模态** 等前沿方向。

- **总体趋势**：今日论文从 LLM 后训练主线向外拓展——科学领域（分子/化学）的 foundation model 表征设计、Agent 长期记忆的范式反思、以及扩散语言模型与高效视频多模态成为新增长点；可解释性与临床推理评测也开始系统化。
- **质量分布**：今日推荐的论文评分在 8.27–8.8 之间，整体质量均衡，前 3 篇在方法新颖性与理论支撑上尤为突出。
- **研究热点**：
  - **科学基础模型**：HGR 用高阶文法统一分子生成与表征学习，为化学 foundation model 提供拓扑感知的输入表征。
  - **Agent 记忆范式**：Mem++ 提出"读取时选择而非写入时蒸馏"的非破坏性记忆，回答"某时刻哪个版本生效"。
  - **扩散语言模型**：HC-DLM 将连续潜变量作为唯一持久状态，耦合离散 token 与连续轨迹，统一结构化推理与语言建模。
- **阅读建议**：建议从 **Mem++**（范式级、易理解）与 **HC-DLM**（方法新颖）入手，再读 **HGR** 了解科学 foundation model 的表征设计；关注视频多模态的读者可重点阅读 **VETO** 与 **ATPO**，其余论文按个人方向选读。

### [[20_Research/Papers/大模型/Higher-Order_Molecular_Grammars_for_Generative_and_Foundation_Models_in_Chemistry|HGR: Higher-Order Molecular Grammars for Generative and Foundation Models]]
- **作者**：Yiming Huang, Yujie Zeng, Vijay Prakash Dwivedi, Simone Foti, Jianmin Wang, Jure Leskovec, Tolga Birdal
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.02186) | [PDF](https://arxiv.org/pdf/2610.02186)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/大模型/Higher-Order_Molecular_Grammars_for_Generative_and_Foundation_Models_in_Chemistry|HGR]]

**一句话总结**：用"组合复形 + 上下文无关高阶文法"将分子的高阶拓扑（环体系、motifs）序列化为产生式规则，使标准序列模型可直接处理且解码天然合法。

![[2610.02186_page1.png|600]]

**核心贡献/观点**：
- 提出高阶文法表征 HGR，把分子提升为组合复形并解析为产生式规则序列，显式编码高阶拓扑。
- 通过文法序列化避免显式高阶编码的高计算开销，同时生成 100% 合法。
- 构建环富集基准 RingDiv（118 万分子）与环多样性指数 RDI，缓解基准对简单环体系的偏置。

**关键结果**：分子生成五个基准 FCD 全部第一；表征学习 MoleculeNet 七个基准平均 AUC 最高，相对最强基线 probing 提升 8.3 分、微调提升 3.3 分。

### [[20_Research/Papers/大语言模型/Mem++_Non-Destructive_Memory_for_Long-Term_Organizational_LLM_Agents|Mem++: Non-Destructive Memory for Long-Term Organizational LLM Agents]]
- **作者**：Ahmad Yehia, Aly O. Abdelkareem, Islam Ahmed, Hesham Omran, Khaled Alashmouny, Christian Claudel, Abduallah Mohamed
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.02002) | [PDF](https://arxiv.org/pdf/2610.02002)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/大语言模型/Mem++_Non-Destructive_Memory_for_Long-Term_Organizational_LLM_Agents|Mem++]]

**一句话总结**：把 Agent 记忆从"写入时蒸馏"改为"读取时选择"，完整保留每份文档及其日期/作者，按问题时间点检索历史版本。

![[2610.02002_page1.png|600]]

**核心贡献/观点**：
- 点明写入时压缩会提前固化"能回答什么"的问题，提出非破坏性记忆范式。
- 写入时零生成成本、完整存储文档，读取时仅检索截至问题时间点的文档并融合词汇+语义排序。
- 不覆盖旧版本，把"选哪个版本"的决策交还回答模型。

**关键结果**：在 OrgMemBench 上超最强记忆基线 8.0–13.1 分，gpt-4.1-mini 下总分超 RAG 2.6 分；LoCoMo 平均 LLM-judge 分数最高。

### [[20_Research/Papers/大语言模型/Hierarchical_Continuous_Diffusion_Language_Models|HC-DLM: Hierarchical Continuous Diffusion Language Models]]
- **作者**：Hui Ren, Zihan Li, Chang Liu, Huidong Liu, Alexander Schwing
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.02193) | [PDF](https://arxiv.org/pdf/2610.02193)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/大语言模型/Hierarchical_Continuous_Diffusion_Language_Models|HC-DLM]]

**一句话总结**：让连续潜变量成为唯一持久生成状态，token 每步从潜变量读出并作为脚手架反哺更新，用变分界统一 token 依赖与连续-离散耦合。

![[2610.02193_page1.png|600]]

**核心贡献/观点**：
- 提出层级耦合范式：连续潜在轨迹与离散 token 在单一去噪过程中耦合，而非拼接式设计。
- 训练目标由 token 似然的变分界推导，方法具有原则性。
- 统一处理结构化推理（Sudoku、Countdown）与语言建模（LM1B）。

**关键结果**：在匹配模型规模下，Sudoku/Countdown 的谜题准确率与 LM1B 的生成困惑度均优于离散与连续扩散基线。

### [[20_Research/Papers/多模态/VETO_Video_Efficient_Token_Optimization_for_Vision_Language_Models|VETO: Video Efficient Token Optimization for Vision Language Models]]
- **作者**：Gueter Josmy Faure, Hao Ping Wang, Min-Hung Chen, Winston H. Hsu
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.01785) | [PDF](https://arxiv.org/pdf/2610.01785)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：用"先帧内压缩、后帧间压缩"的层级双轴 token 优化，突破单轴压缩的效率地板，加速长视频 VLM 推理。

**核心贡献/观点**：
- 提出 dual-axis 压缩：帧内用 optimal-transport 启发匹配合并语义相似 token，帧间识别并合并时间冗余帧。
- 关键设计是层级顺序：先压缩空间维度，大幅降低后续全局时间匹配成本。
- 训练可选（training-optional）插件，通用适用于 LLaVA-OneVision、InternVL-2.5、LongVA。

**关键结果**：最多 45% 推理加速（LLaVA-OneVision-7B）；10% token 预算下精度 55.7%，超 VFlowOpt（54.9%）、VisionZip（52.6%）、FastV（47.9%）。

### [[20_Research/Papers/大语言模型/A_rubric_landscape_for_evaluating_clinical_reasoning_in_large_language_models_what_exists,_what_is_missing,_and_what_needs_to_be_combined|A Rubric Landscape for Evaluating Clinical Reasoning in LLMs]]
- **作者**：Zhangshu Joshua Jiang, Zina Ibrahim, James T. Teo
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.01938) | [PDF](https://arxiv.org/pdf/2610.01938)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：系统综述 LLM 临床推理评测的评分量规（rubric），指出没有任何单一工具覆盖全部六维，并给出组合式设计原理。

**核心贡献/观点**：

### [[20_Research/Papers/大语言模型/Asynchronous_LLM_Post-Training_Group-Mass_Capping_and_Convergence_Analysis|GMC-GRPO: Asynchronous LLM Post-Training with Group-Mass Capping]]
- **作者**：Qijia He, Ruinan Jin, Jun Luo, Shaofeng Zou, Yingbin Liang
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.01896) | [PDF](https://arxiv.org/pdf/2610.01896)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：推导异步 GRPO 的收敛界，刻画 stale rollout 的延迟-偏差权衡，并提出 group mass capping 方法降低延迟影响。

**核心贡献/观点**：

### [[20_Research/Papers/多模态/MoLE_Mixture_of_Latent_Experts_for_Complementary_Visual_Reasoning|MoLE: Mixture of Latent Experts for Complementary Visual Reasoning]]
- **作者**：Yingcheng Liu, Tianyi Jiang, Yujuan Ding, jiangbo Ai, Xun Jiang, Guoqing Wang, Wei Ye, Yi Bin
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.01917) | [PDF](https://arxiv.org/pdf/2610.01917)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：用 Mixture of Latent Experts 让不同潜 token 提取互补视觉信息，作为专门化视觉专家，而非简单增加潜 token 预算。

**核心贡献/观点**：
- 指出共享 value 投影让多个潜 token 访问相同视觉证据、产生冗余潜表征的问题。
- MoLE 同时控制每个潜视觉专家"观察什么证据"与"如何变换证据"，用潜 summary 专家聚合互补表征。
- 两阶段训练先强制视觉证据走潜路径、再恢复直接视觉访问，无需预定义专家角色或中间目标。

**关键结果**：五个视觉推理基准平均 78.6 分，超数据匹配 SFT 4.9 分、超最强潜推理基线 3.6 分；掩码潜路径后平均性能下降 9.2 分。

### [[20_Research/Papers/大语言模型/Beyond_Linear_Concepts_Discovering_and_Aligning_Non-Linear_Concept_Manifolds_in_Large_Language_Models|Beyond Linear Concepts: Discovering Non-Linear Concept Manifolds in LLMs]]

**一句话总结**：将概念建模为低维流形而非线性方向，提出概念对齐分数 CBA，揭示 LLM 内部的非线性格局与跨层/跨模型结构。

### [[20_Research/Papers/多模态/Controllable_Multi-label_Video_Safety_Detection_via_Adaptive_Tversky_Policy_Optimization|ATPO: Controllable Multi-label Video Safety Detection]]
- **作者**：Guangyu Yang, Jingbiao Mei, Mingsheng Sun, Jinghong Chen, Yingtong Bu, Pengda Qin, Da Chen, Bill Byrne
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.02019) | [PDF](https://arxiv.org/pdf/2610.02019)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：用 RL 框架 + Adaptive Tversky Reward 做多标签视频安全检测，动态调整假阳/假阴惩罚以支持可控的精确率-召回率权衡。

**核心贡献/观点**：
- 指出视频安全检测被简化为二分类、忽略多标签本质，且静态目标不支持可控 precision-recall 权衡。
- 提出 ATPO：Adaptive Tversky Reward（ATR）在训练中动态调整 FP/FN 惩罚。
- 支持按审核管线与危险类别的异质策略需求，可靠调节 precision-recall 工作点。

**关键结果**：SafeWatch-Bench 上 Jaccard Index 从 40.66 提升至 75.44（Real 子集），ATR 实现可控工作点调节。
