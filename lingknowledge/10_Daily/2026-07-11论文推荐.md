## 今日概览

今日推荐的 5 篇论文全部聚焦于 **LLM Agent 与强化学习** 这一前沿交叉领域，涵盖了单智能体工具使用、多智能体协作、通用 RL 训练框架以及 GUI 智能体等多个子方向。

- **总体趋势**：强化学习已成为提升 LLM Agent 能力的核心范式，近一年来从单轮奖励优化快速演进到多轮交互 RL、树搜索增强探索、多智能体协同训练等更复杂的训练范式。GRPO/PPO 等策略优化算法被广泛应用于 Agent 训练。
- **质量分布**：今日推荐的论文评分在 2.14-3.19 之间，均为 Semantic Scholar 热门论文，引用数从 22 到 154 不等。其中 Tree-GRPO 已被 ICLR 2026 接收，UI-TARS-2 引用数最高（154次）。
- **研究热点**：
  - **多轮交互 RL**：将 LLM Agent 的多轮交互建模为 MDP，使用 RL 优化对话和工具调用策略
  - **树搜索增强 RL**：利用树结构轨迹共享前缀降低 rollout 成本，同时提取过程监督信号
  - **多智能体 RL 协作**：将 LLM 协作建模为 Dec-POMDP，使用集中式群组优势优化分布式执行
  - **通用 Agent RL 框架**：解耦 Agent 执行与 RL 训练，实现零代码修改的通用训练
  - **GUI Agent RL**：面向图形界面的原生 Agent 模型，结合数据飞轮与多轮 RL
- **阅读建议**：推荐从 Tree-GRPO（ICLR 2026 接收，方法新颖）开始，然后阅读 Agent Lightning（工程框架，实用性强），最后阅读 UI-TARS-2（综合性强，覆盖 GUI 全栈），可根据兴趣深入 MUA-RL 和 MAGRPO。

### [[MUA-RL_Multi-turn_User-interacting_Agent_Reinforcement_Learning_for_agentic_tool_use|MUA-RL: Multi-turn User-interacting Agent Reinforcement Learning for Agentic Tool Use]]
- **作者**：Weikang Zhao, Xili Wang, Chengdi Ma, Lingbin Kong, Zhaohua Yang, Mingxiang Tuo, Xiaowei Shi, Yitao Zhai, Xunliang Cai
- **机构**：Meituan Inc., 中科院自动化所, 北京大学
- **链接**：[arXiv](https://arxiv.org/abs/2508.18669) | [PDF](https://arxiv.org/pdf/2508.18669)
- **来源**：arXiv (2025-08-26)
- **详细报告**：[[20_Research/Papers/强化学习与智能体/MUA-RL_Multi-turn_User-interacting_Agent_Reinforcement_Learning_for_agentic_tool_use|MUA-RL 详细分析]]
- **笔记**：--

**一句话总结**：首次将 LLM 模拟用户集成到强化学习训练循环中，使 Agent 在多轮动态交互中自主学习高效沟通与工具调用策略。

![[multiturn.drawio.png|600]]

**核心贡献/观点**：
- 提出 MUA-RL 框架，首次将 LLM 模拟的动态用户纳入 Agent 强化学习训练循环
- 设计多轮交互 RL 训练范式，让 Agent 在沟通中迭代精化用户需求理解
- 在 TAU2（Retail/Airline/Telecom）、BFCL-V3 Multi Turn、ACEBench 等基准上，MUA-RL-32B 超越或匹敌 DeepSeek-V3、Qwen3-235B 等更大模型

**关键结果**：MUA-RL-32B 在 TAU2 Retail 达 67.3、TAU2 Airline 达 45.4、BFCL-V3 Multi Turn 达 28.4、ACEBench Agent 达 82.5。

### [[Tree_Search_for_LLM_Agent_Reinforcement_Learning|Tree-GRPO: Tree Search for LLM Agent Reinforcement Learning]]
- **作者**：Yuxiang Ji, Ziyu Ma, Yong Wang, Guanhua Chen, Xiangxiang Chu, Liaoni Wu
- **机构**：阿里高德 (AMAP, Alibaba Group), 厦门大学, 南方科技大学
- **链接**：[arXiv](https://arxiv.org/abs/2509.21240) | [PDF](https://arxiv.org/pdf/2509.21240)
- **来源**：arXiv (2025-09-25), **ICLR 2026**
- **详细报告**：[[20_Research/Papers/强化学习与智能体/Tree_Search_for_LLM_Agent_Reinforcement_Learning|Tree-GRPO 详细分析]]
- **笔记**：--

**一句话总结**：提出基于树搜索的 GRPO 方法，用 1/4 的 rollout 预算超越链式 RL 基线，且仅凭最终奖励即可自动提取步骤级过程监督信号。

![[pipeline_page1.png|600]]

**核心贡献/观点**：
- 提出 Tree-GRPO，将 ReAct 步骤级节点组织为搜索树，共享前缀降低 rollout 成本
- 树结构轨迹天然允许仅凭最终奖励回溯构建步骤级过程监督，等价于隐式步骤级偏好学习
- 设计树内（intra-tree）和树间（inter-tree）两级分组相对优势估计
- 在 11 个数据集、3 类 QA 任务上全面超越链式 RL 方法

**关键结果**：仅需链式 GRPO 的 1/4 预算即可超越其性能，理论证明了树内 GRPO 与步骤级 DPO 的等价性。

### [[LLM_Collaboration_With_Multi-Agent_Reinforcement_Learning|MAGRPO: LLM Collaboration With Multi-Agent Reinforcement Learning]]
- **作者**：Shuo Liu, Zeyu Liang, Xueguang Lyu, Christopher Amato
- **机构**：Northeastern University (Khoury College of Computer Sciences)
- **链接**：[arXiv](https://arxiv.org/abs/2508.04652) | [PDF](https://arxiv.org/pdf/2508.04652)
- **来源**：arXiv (2025-08-06)
- **详细报告**：[[20_Research/Papers/强化学习与智能体/LLM_Collaboration_With_Multi-Agent_Reinforcement_Learning|MAGRPO 详细分析]]
- **笔记**：--

**一句话总结**：将 LLM 协作建模为合作式多智能体强化学习问题，提出 MAGRPO 算法实现 LLM Agent 的高效协同训练。

![[MLRL_page1.png|600]]

**核心贡献/观点**：
- 首次将 LLM 多智能体协作建模为 Dec-POMDP，形式化多智能体 RL 训练框架
- 提出 MAGRPO（Multi-Agent Group Relative Policy Optimization），结合 GRPO 与 MARL 技术（MAPPO）
- 使用集中式群组相对优势进行联合优化，同时保持分布式执行
- 在写作（TLDR 摘要、arXiv 扩展）和编程（HumanEval、CoopHumanEval）任务上验证协作效果

**关键结果**：MAGRPO 微调后的 MAS 在写作和编程协作任务中生成更高质量的回复，GitHub 代码开源。

### [[Agent_Lightning_Train_ANY_AI_Agents_with_Reinforcement_Learning|Agent Lightning: Train ANY AI Agents with Reinforcement Learning]]
- **作者**：Xufang Luo, Yuge Zhang, Zhiyuan He, Zilong Wang, Siyun Zhao, Dongsheng Li, Luna K. Qiu, Yuqing Yang
- **机构**：Microsoft Research
- **链接**：[arXiv](https://arxiv.org/abs/2508.03680) | [PDF](https://arxiv.org/pdf/2508.03680)
- **来源**：arXiv (2025-08-05)
- **笔记**：--

**一句话总结**：微软提出的通用 Agent RL 训练框架，实现 Agent 执行与 RL 训练的完全解耦，支持 LangChain/AutoGen 等框架的零代码集成。

**核心贡献/观点**：
- 首次实现 Agent 执行与 RL 训练的完全解耦，支持 LangChain、OpenAI Agents SDK、AutoGen 等框架零代码修改集成
- 将 Agent 执行建模为 MDP，定义统一数据接口，提出分层 RL 算法 LightningRL
- 信用分配模块将轨迹级奖励分解为单次调用训练样本，支持多智能体和动态工作流
- 引入 Training-Agent Disaggregation 架构和 OpenTelemetry 可观测性

**关键结果**：在 Text-to-SQL、RAG（MuSiQue 多跳推理）、数学 QA + 工具使用三个任务上均展现稳定持续的性能提升。

### [[UI-TARS-2_Technical_Report_Advancing_GUI_Agent_with_Multi-Turn_Reinforcement_Learning|UI-TARS-2: Advancing GUI Agent with Multi-Turn Reinforcement Learning]]
- **作者**：Kai Shen, Wenhao Huang, Minchao Wang, Chen Li, Haoyang Zou 等 (ByteDance Seed 团队)
- **机构**：ByteDance
- **链接**：[arXiv](https://arxiv.org/abs/2509.02544) | [PDF](https://arxiv.org/pdf/2509.02544)
- **来源**：arXiv (2025-09-02)
- **笔记**：--

**一句话总结**：字节跳动推出的原生 GUI Agent 模型，通过数据飞轮、多轮 RL 和混合 GUI 环境，在多项 GUI 基准上大幅超越 Claude 和 OpenAI Agent。

**核心贡献/观点**：
- 数据飞轮：通过持续预训练→SFT→拒绝采样→多轮 RL 的循环共同进化模型和训练数据
- 稳定化多轮 RL 框架：异步 rollout、奖励塑形、自适应 GAE 和价值预训练
- 混合 GUI-SDK 环境：集成文件系统、终端和外部工具，突破纯 GUI 操作限制
- 统一沙盒平台：支持 Windows/Ubuntu/Android 云端 VM 和浏览器游戏沙盒

**关键结果**：Online-Mind2Web 88.2、OSWorld 47.5、WindowsAgentArena 50.6、AndroidWorld 73.3；游戏环境得分 59.8（约人类 60%）；超越 OpenAI CUA 2.4×、Claude Computer Use 2.8×。
