## 今日概览

今日推荐的 10 篇论文主要聚焦于**大语言模型工具调用与 Agent**、**多语言语用与推理评估**和**机制可解释性**等前沿方向。

- **总体趋势**：今日论文呈现"从能力评测走向机制理解、从单语言走向多语言文化"的迁移。一方面，Agent 工具调用（Harness Engineering、SAGE、ACToR）持续向更可靠、更低成本的方向演进；另一方面，语用/文化理解（VakyArth、MemeCULT-1K、文化变迁表示）与机制可解释性（抑郁 Symptom Vectors）成为新的评测与理解焦点。
- **质量分布**：今日推荐的论文评分在 8.63-10.63 之间，整体质量较高，评分最高的三篇均为大语言模型方向，且均已生成图文并茂的详细分析笔记。
- **研究热点**：
  - **Agent 工具调用与编排**：Tool Primitives/HEART、SAGE 选择性指导、ACToR 关键 token 检索，共同主题是"在成本与可靠性约束下更聪明地调用工具/上下文"。
  - **多语言与语用/文化理解**：VakyArth 与 MemeCULT-1K 揭示"翻译 ≠ 理解"，文化语境是当前多模态/多语言模型的共同短板。
  - **机制可解释性**：从抑郁症状向量到文化变迁表示，用可解释性技术把黑盒表征与临床/社会科学信号对齐。
- **阅读建议**：建议先读评分最高的《Harness Engineering in LLM Tool Use》（工具调用范式新概念），再读《VakyArth》（评测方法警示）与《Interpretable Symptom Vectors》（可解释性 × 医疗交叉）；对后训练预算分配感兴趣的读者可跟进《Scaling Near-Optimal SFT-RL》。

### [[Harness_Engineering_in_LLM_Tool_Use_via_Agent-Native_Reusable_Tool_Primitives|Harness Engineering in LLM Tool Use via Agent-Native Reusable Tool Primitives]]
- **作者**：Haibo Jin, Suijin Wang, Xucheng Yu, Haojing Luo, Haohan Wang
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2609.01736v1) | [PDF](https://arxiv.org/pdf/2609.01736v1)
- **来源**：arXiv
- **笔记**：--
- **详细报告**：[[20_Research/Papers/大语言模型/Harness_Engineering_in_LLM_Tool_Use_via_Agent-Native_Reusable_Tool_Primitives|Harness Engineering in LLM Tool Use]]

**一句话总结**：提出 Tool Primitives 把工具调用从刚性 API schema 抽象为自然语言接口，配合 ToolFace 工具仓库与 HEART（Planner/Router/Verifier）框架，实现大规模工具目录下可靠、低成本的 agent 工具编排。

![[toolprimitives0506_2_page1.png|600]]

**核心贡献/观点**：
- **Tool Primitives**：用自然语言作为工具调用接口，每个工具包裹在负责 schema 解析与执行的 LLM 接口内。
- **ToolFace**：托管 25,519 个函数的集中式仓库，推理时按需动态检索相关工具，避免枚举全部 schema。
- **HEART**：由 Planner、Router、Verifier 组成的编排框架，支持动态规划、多步执行与反馈驱动恢复。

**关键结果**：五个基准上平均超 SFT 模型 10%、超 GPT-5.4/Claude-4.6-Sonnet/Gemini-3.1-Pro 6%，API 成本降低最多 85%；50 个现实任务完成率 84%（前沿商业模型平均 22% 的 3.8×）。

### [[VakyArth_Evaluating_Pragmatic_Competence_in_LLMs_across_Indic_Languages|VakyArth: Evaluating Pragmatic Competence in LLMs across Indic Languages]]
- **作者**：Usneek Singh, Poorvaja Veera Balaji Kumar, Parth Nanda, Anand Madhusoodanan, Geyang Guo, Wei Xu, Junyi Jessy L
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2609.01788v1) | [PDF](https://arxiv.org/pdf/2609.01788v1)
- **来源**：arXiv
- **笔记**：--
- **详细报告**：[[20_Research/Papers/大语言模型/VakyArth_Evaluating_Pragmatic_Competence_in_LLMs_across_Indic_Languages|VakyArth]]

**一句话总结**：首个面向印度语系语言的语用基准，覆盖 4 语言 × 5 语用现象 × 3 任务，揭示多语言 LLM 在语用含义上的持续失败，以及"翻译能力 ≠ 语用理解"。

![[Benchmark-Design-Page-2.drawio_page1.png|600]]

**核心贡献/观点**：
- 首个 Indic 语用基准 VakyArth，覆盖印地语、旁遮普语、泰米尔语、马拉雅拉姆语。
- 评估 5 类语用现象（指示语、言语行为、蕴涵、社会语用、连贯性），条目全部由母语者撰写。
- 揭示自动翻译指标会漏掉"流畅但语用不忠实"的输出。

**关键结果**：多语言 LLM 在印度语系语用含义上持续失败；所有模型-语言组合中 MCQ 准确率 > NLI；翻译性能与语用理解脱钩。

### [[Interpretable_Symptom_Vectors_for_Depression_in_a_Large_Language_Model|Interpretable Symptom Vectors for Depression in a Large Language Model]]
- **作者**：Fangyi Zhu, Ajay Subramanian, Allison Constant, Camille Wang, Ravish Gupta, Corey J. Keller
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2609.01832v1) | [PDF](https://arxiv.org/pdf/2609.01832v1)
- **来源**：arXiv
- **笔记**：--
- **详细报告**：[[20_Research/Papers/大语言模型/Interpretable_Symptom_Vectors_for_Depression_in_a_Large_Language_Model|Interpretable Symptom Vectors]]

**一句话总结**：用机制可解释性在 Gemma-3-27B-PT 残差流中提取与临床对齐的抑郁"Symptom Vectors"，第 21 层的单一抑郁向量可区分抑郁/非抑郁文本（AUC=0.789）。

![[1.pipeline_page1.png|600]]

**核心贡献/观点**：
- 定位到症状群在第 21 层几何分离程度最高（多距离度量一致）。
- Semantic Projection 提取的逐症状系数保持临床医生标注的等级排序（mood/somatic/suicidality）。
- 提出情绪效价门控（valence gate）限制症状投影仅作用于抑郁言语。

**关键结果**：单一抑郁向量区分抑郁/非抑郁文本 AUC=0.789，揭示去相关、临床对齐的可读症状信号。

### [[Selective_Agent_Guidance_via_Entropy_Learning_Autonomous_Policies_from_Imperfect_VLM_Teachers|Selective Agent Guidance via Entropy (SAGE)]]
- **作者**：Giovanni Bonetta, Matteo Merler, Davide Zago, Rossella Cancelliere, Bernardo Magnini
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2609.01567v2) | [PDF](https://arxiv.org/pdf/2609.01567v2)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：SAGE 框架仅在学习者不确定时查询 VLM 教师，用环境优势加权蒸馏到轻量 RL 策略，实现部署时零 VLM 调用。

**核心贡献/观点**：
- 从"昂贵、不完美但信息量大"的 VLM 教师学习轻量自主策略。

**关键结果**：稀疏奖励视觉推理/导航任务上超越无指导 RL，部分环境中学到的策略甚至超越其 VLM 教师。

### [[Accurate_in_space,_unreliable_in_time_how_LLMs_represent_national_cultural_change|Accurate in space, unreliable in time]]
- **作者**：Yalda Daryani, Miranda Bogen, Madeleine I. G. Daepp
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2609.01902v1) | [PDF](https://arxiv.org/pdf/2609.01902v1)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：用 20 余年世界价值观调查数据，发现 LLM 对国家文化变迁的表示"空间上准、时间上不可靠"，存在时间扁平化。

### [[IntroConformal_Conformal_Factuality_Guarantees_for_Large_Vision-Language_Models_via_Introspective_Signals|IntroConformal: Conformal Factuality Guarantees for LVLMs]]
- **作者**：Md. Atabuzzaman, Christian Alexander, Chris Thomas
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2609.01375v1) | [PDF](https://arxiv.org/pdf/2609.01375v1)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：无需训练的 Conformal Risk Control（CRC）框架，用内省信号（层语义稳定性、验证概率）为大型视觉语言模型提供有限样本、分布无关的事实性保证。

**核心贡献/观点**：
- 用模型自身内省信号替代外部验证器或生成时置信度信号。
- 提出层间语义稳定性（layer-wise semantic stability）与验证概率（verification probability）两种 conformal 分数。
- 训练无关，跨多种 LVLM 架构。

**关键结果**：满足 conformal 风险保证的同时显著降低弃答率，claim 级区分度与外部验证器基线相当或更优。

### [[Adaptive_Critical_Token-Aware_Retrieval_for_Repository-Level_Code_Generation|Adaptive Critical Token-Aware Retrieval for Repository-Level Code Generation (ACToR)]]
- **作者**：Kefeng Duan, Dewu Zheng, Yanlin Wang, Terry Yue Zhuo, Mingwei Liu, Jianxing Yu, Jiachi Chen, Ensheng Shi, Xilin Liu, Yuchi Ma, Zibin Zheng
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2609.01601v1) | [PDF](https://arxiv.org/pdf/2609.01601v1)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：针对仓库级代码生成的"关键 token"自适应检索框架 ACToR，在自回归生成时识别关键 token 并按需检索仓库上下文。

**核心贡献/观点**：
- 提出"关键 token"概念：自回归生成中少数决定性位置一旦出错即导致后续语义路径错误。
- ACToR 在生成过程中识别关键 token 并触发定向检索，在决定性位置提供仓库上下文。
- 设计位置感知加权（position-aware weighting）优化稠密检索器。

**关键结果**：在 RepoExec 与 CoderEval 上相对提升 8.4% 与 15.4%，系统量化关键 token 在生成失败中的核心作用。
