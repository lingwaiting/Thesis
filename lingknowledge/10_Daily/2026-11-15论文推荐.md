### [[Metal_Sandbox_Isolated_Execution_and_Command_Scheduling_for_GPU_Coding_Agents_on_Apple_Silicon|Metal Sandbox: Isolated Execution and Command Scheduling for GPU Coding Agents on Apple Silicon]]
- **作者**：Haozhe Wang, Lina Chen, Fanqi Wan, Qi Han, Yinmin Zhang, Zheng Ge, Daxin Jiang, Junchi Yan
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.17294) | [PDF](https://arxiv.org/pdf/2611.17294)
- **来源**：arXiv

- **推荐评分**：8.13

**一句话总结**：Metal Sandbox 面向 Apple Silicon 上的 GPU 编码智能体，用"受限文件访问 + 原生命令执行 + 跨节点命令级调度"解决 GPU 大量闲置问题。

![[figure_03_cluster_layout_page1.png|600]]

**核心贡献/观点**：
- 每个智能体保留独立工作区与私有开发环境，实现受限按实例文件访问。

### [[Look_It_Up_Multi-bit_LLM_Watermarking_via_Codebook_Search|Look It Up: Multi-bit LLM Watermarking via Codebook Search]]
- **作者**：Jarosław Janas, Paweł Morawiecki, Josef Pieprzyk
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.16890) | [PDF](https://arxiv.org/pdf/2611.16890)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/大语言模型/Look_It_Up_Multi-bit_LLM_Watermarking_via_Codebook_Search|详细分析]]
- **推荐评分**：8.10

**一句话总结**：用"码本 + 最近码字匹配"实现短文本多比特水印，把 n 比特载荷映射为更长码字并在生成期嵌入，可靠恢复来源归属。

![[watermark_codebook_scheme.png|600]]

**核心贡献/观点**：
- 将 n 比特载荷映射为更长 u 比特码字，用冗余换取纠错能力。
- 生成期通过 token 级 logit 偏置嵌入码字，提取期用汉明/莱文斯坦距离匹配最近码字。
- 莱文斯坦变体提升对删除与轻度改写的韧性；并系统分析碰撞概率、码字间距、提取时间等。

**关键结果**：200-token 生成上 16-24 比特载荷近乎完美恢复；基础模型 127-token 表现强；极短文本 + 低熵（指令微调模型）下可靠性下降。

### Introducing Feedback Delays to Non-Delayed Adversarial MDPs: Optimal √S and √K Dependencies in Tabular and Linear AMDPs
- **作者**：Aarush Kulkarni, Khang Nguyen, William Chang, Yan Dai
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.17214) | [PDF](https://arxiv.org/pdf/2611.17214)
- **来源**：arXiv
- **笔记**：--
- **推荐评分**：7.87

**一句话总结**：在对抗 MDP 中"主动引入反馈延迟"来估计变化策略的 Q 函数，首次在表格与线性 AMDP 上同时取得 √S 和 √K 最优遗憾界。

**核心贡献/观点**：

### LazyWeights: Decode-on-Demand Edge LLMs
- **作者**：Arnab Sanyal, Gourav Datta, Sandeep P. Chinchali
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.17108) | [PDF](https://arxiv.org/pdf/2611.17108)
- **来源**：arXiv
- **笔记**：--
- **推荐评分**：7.60

**一句话总结**：LazyWeights 保留现有量化格式但用哈夫曼无损压缩权重码，在 DRAM 与 L2 之间按需解码，显著压缩边缘 LLM 的体积与能耗。

**核心贡献/观点**：
- 调优 GPTQ 使整数码可压缩，再用交错车道哈夫曼无损编码。
