### [[20_Research/Papers/强化学习与智能体/Tree_Search_for_LLM_Agent_Reinforcement_Learning|Tree-GRPO: Tree Search for LLM Agent Reinforcement Learning]]
- **作者**：Yuxiang Ji, Ziyu Ma, Yong Wang, Guanhua Chen, Xiangxiang Chu, Liaoni Wu
- **机构**：阿里高德 (AMAP, Alibaba Group), 厦门大学, 南方科技大学
- **链接**：[arXiv](https://arxiv.org/abs/2509.21240) | [PDF](https://arxiv.org/pdf/2509.21240)
- **来源**：Semantic Scholar（热门论文）
- **详细报告**：[[20_Research/Papers/强化学习与智能体/Tree_Search_for_LLM_Agent_Reinforcement_Learning|Tree-GRPO 深度分析]]
- **笔记**：已有详细分析（评分 8.0/10，🏆 **ICLR 2026**）
- **代码**：[GitHub](https://github.com/AMAP-ML/Tree-GRPO)
- **引用**：51

**一句话总结**：将树搜索引入 GRPO，通过共享前缀在固定预算内增加 rollout 数量，并利用树结构自然构建过程监督信号。

![[tree_grpo_framework_page1.png|600]]

**核心贡献/观点**：
- 提出 Tree-GRPO：基于树搜索的分组 Agent RL 方法，每个树节点代表完整的 agent 交互步骤
- 树搜索采样通过共享前缀，在固定 token/tool call 预算下显著增加 rollout 数量
- **关键发现**：树结构轨迹天然允许仅使用结果奖励构建步骤级过程监督信号
- 理论分析证明 intra-tree GRPO 等价于 step-level direct preference learning
- 在 11 个数据集、3 类 QA 任务上一致超越 chain-based RL

**关键结果**：跨 11 个数据集一致优于链式 RL 方法，为 Agent RL 的过程监督提供了优雅的理论基础。
