## 今日概览

今日推荐的 10 篇论文主要聚焦于 **LLM Agent 的自我改进与评估**、**LLM 垂直领域应用（心理健康/论证挖掘）** 和 **强化学习与世界模型** 等前沿方向。

- **总体趋势**：今日论文呈现两大主线——一是 LLM Agent 系统的工程化与泛化（harness 自我改进、计算机使用智能体评估、对齐数据标注、交付可靠性），二是决策/控制类方法（世界模型、图强化学习、机器人操作）；同时 LLM 向心理健康、论证挖掘等垂直领域加速渗透。
- **质量分布**：今日推荐的论文评分在 8.4–9.2 之间，整体质量较高，其中 3 篇超过 8.8 分，值得重点关注。
- **研究热点**：
  - **Agent Harness 自我改进与评估**：RRSI 把正则化引入 harness 进化、OSWorld-Pro 做过程级 CUA 评估、Trains but Doesn't Learn 关注交付可靠性，共同刻画了 Agent 从"能刷分"到"可信交付"的进阶。
  - **LLM 垂直领域应用**：心理健康（三阶段演化综述）与论证挖掘（生成式组件检测）代表 LLM 向专业化场景的下沉。
  - **世界模型与决策**：D-JEPA 将决策对齐引入潜在世界模型，图强化学习与机器人修剪则展示了 RL 在组合优化与实体操控上的进展。
- **阅读建议**：优先阅读 **RRSI**（评分最高，来自 Google，Agent 自我改进泛化性是热点），其次 **OSWorld-Pro**（NVIDIA 的过程级智能体评估，实用性强）与 **D-JEPA**（世界模型 + 决策对齐，方法新颖）；对 LLM 应用感兴趣的读者可直接看 **Mental Health Survey**（优质综述，附带开源资源库），其余论文可按兴趣选择性阅读。

### [[RRSI_Regularized_Recursive_Self-Improvement_of_Agent_Harnesses|RRSI: Regularized Recursive Self-Improvement of Agent Harnesses]]
- **作者**：Peng Xia, Rujun Han, Zifeng Wang, Yanfei Chen, Yufan Zhang, Yoonho Lee, Chengsong Huang, Han Yu, Zhongying CuiZhu, Yifei Ming, Huaxiu Yao, Burak Gokturk, Tomas Pfister, Chen-Yu Lee
- **机构**：Google Research
- **链接**：[arXiv](https://arxiv.org/abs/2609.24972) | [PDF](https://arxiv.org/pdf/2609.24972)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/RRSI_Regularized_Recursive_Self-Improvement_of_Agent_Harnesses|RRSI 深度分析]]
- **笔记**：已有详细分析

**一句话总结**：将正则化思想引入 Agent harness 的递归自我改进，通过约束候选的"提议"与"选择"来防止对训练任务的过拟合，从而提升跨基准泛化能力。

![[pipeline_page1.png|600]]

**核心贡献/观点**：
- 首次将机器学习正则化原则系统性地引入 harness 自我改进，提出"Agent 层面的过拟合"问题。
- 提议器采用时间退火预算限制编辑数量并鼓励探索未覆盖轨迹；选择器用 critic + pruner 筛选掉基准特化/低价值改动。
- 显式追求"可复用机制"而非"应试式特化"，改进了自我改进类系统的评估范式。

**关键结果**：8 个基准上进化 split 最高 **+14.1 分**、5 个分布外基准最高 **+4.7 分**，harness 运行时策略 token 减少 **30%**。

### [[D-JEPA_A_Decision-Aligned_Latent_World_Model|D-JEPA: A Decision-Aligned Latent World Model]]

### [[onPanda_Efficient_Annotation_of_On-Policy_Alignment_Data_for_LLMs_and_Agents_via_Token-Level_Correction|onPanda: Efficient Annotation of On-Policy Alignment Data via Token-Level Correction]]

**核心贡献/观点**：
