## 今日概览

今日推荐的 10 篇论文主要聚焦于**LLM 智能体与多智能体系统的监督与自进化**、**世界模型与具身智能**以及**长上下文与智能体记忆**等前沿方向。

- **总体趋势**：本日论文呈现出对"智能体系统如何被训练、监督和自改进"的集中关注。从外置转向智能体（steering）到 librarian agent 主动整理语料、再到 AI4AI 自主 ML 工程与自进化模型的选择，研究者们正在从"单一模型能力"转向"智能体系统的组织与调控"。同时，3D 世界建模、机器人灵巧操作等具身智能方向持续活跃。
- **质量分布**：今日推荐的论文评分在 8.93-10.77 之间，整体质量较高。前 3 篇（评分 ≥9.8）分别聚焦智能体转向监督、长上下文工作空间构建、视角解耦 3D 世界建模，均为值得深度阅读的工作。
- **研究热点**：
  - **智能体监督与转向**：从 planning/verification 的局限出发，提出外置 steering agent 实时纠正目标漂移，将干预频率变成部署期可调旋钮。
  - **预期式记忆与长上下文**：Librarian Agents 与 agent memory 评估工作共同推动"智能体记忆"从反应式检索走向主动、可审计的整理。
  - **世界模型与具身智能**：GeoState 的视角解耦几何状态、DemoStream 的 TAMP 批量优化、Dexterity from Supervised Play 的自监督数据采集，体现世界模型驱动具身智能的趋势。
- **阅读建议**：建议优先阅读评分最高的前 3 篇。第 1 篇（Steering）和第 2 篇（Librarian Agents）都来自一线团队（阿里 Qwen/斯坦福），分别代表智能体"实时监督"与"预期式记忆"两个互补方向；第 3 篇（GeoState）为 3D 世界建模提供了清晰的表示层设计原则。

### [[Learning_to_Steer_LLM_Agents_and_Multi-Agent_Systems|Learning to Steer LLM Agents and Multi-Agent Systems]]
- **作者**：Leyang Shen, Yaxin Gong, Yang Zhang, Chenxiao Fan, Jiakai Wang, Dong Wang, Yang Liu, Fuli Feng, Chun Kai Ling, Tat-Seng Chua
- **机构**：新加坡国立大学（NUS）、中国科学技术大学（USTC）、阿里巴巴 Qwen 事业部
- **链接**：[arXiv](http://arxiv.org/abs/2610.22316v1) | [PDF](https://arxiv.org/pdf/2610.22316v1)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/强化学习与智能体/Learning_to_Steer_LLM_Agents_and_Multi-Agent_Systems|详细分析]]
- **笔记**：[[20_Research/Papers/强化学习与智能体/Learning_to_Steer_LLM_Agents_and_Multi-Agent_Systems|Learning to Steer LLM Agents]]
- **评分**：10.77（相关性 4.9 / 新近性 3.0 / 热门度 2.0 / 质量 0.7）
- **领域**：强化学习与智能体 → 目标漂移监督

**一句话总结**：提出一个外置的 steering agent，用"快路径判断 + 慢路径生成"实时纠正 LLM 智能体执行中的目标漂移，并用 RL（pairwise ranking + GRPO）联合训练，在冻结执行器的前提下显著提升单/多智能体系统的性能与效率。

![[2610.22316_page1.png|600]]

**核心贡献/观点**：
- 形式化刻画单智能体与多智能体系统中的**目标漂移（goal drift）**，并论证 planning/verification 的局限
- 设计**快慢双路径**的 steering agent：快路径单 token 判断 steering priority，慢路径 CoT 生成干预动作
- 用 **pairwise ranking + GRPO** 联合训练两条路径，将干预频率变成部署期可调旋钮

**关键结果**：7 个 QA benchmark 上 RL steering 平均 +6.66 分（zero-shot 仅 +1.84），每任务仅 0.93 次 steering action；迁移到 Llama-3.1/Mistral/Phi-4 分别 +15.78/+12.01/+5.92；多智能体场景 +5.34。

- **笔记**：[[20_Research/Papers/大语言模型/Librarian_Agents_Training_LLMs_to_Curate_Long-Context_Workspaces_that_Anticipate_Future_Queries|Librarian Agents]]

- **领域**：大语言模型 → 长上下文与智能体记忆

**一句话总结**：提出 Librarian Agents 框架，训练一个 builder agent 主动将非结构化语料重组为层级文件系统工作空间（合成文件 + 引用链接），用 RL 直接最大化下游回答准确率，实现"预期式"记忆整理。

![[2610.22273_page1.png|600]]

- 将文件系统工作空间构建形式化为 MDP，用 RL 直接优化下游回答性能

**关键结果**：BrowseComp-Plus 上超越最强检索/预计算基线 33 个百分点；BRIGHT 上 zero-shot 迁移平均 +31 点；前期构建成本被多次查询摊销。

### [[GeoState_Learning_View-Decoupled_Geometry_States_for_3D_World_Modeling|GeoState: Learning View-Decoupled Geometry States for 3D World Modeling]]

- **领域**：强化学习与智能体 → 3D 世界建模

**一句话总结**：提出视角解耦的几何状态 GeoState，用 scene tokenizer 聚合多视角 GFM 特征 + 查询条件几何解码器，把"场景是什么"与"如何被观测"分离，用于可预测的 3D 世界建模。

### [[Beyond_Downstream_QA_Rethinking_How_We_Evaluate_Agent_Memory|Beyond Downstream QA: Rethinking How We Evaluate Agent Memory]]
- **作者**：Sebastian-Antonio Toma, Jean de Kernier, Mike Ply, Oliviu Matei
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2610.22209v1) | [PDF](https://arxiv.org/pdf/2610.22209v1)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：揭示 agent memory 评估的"下游 QA 代理"缺陷——它把记忆正确性与检索/生成质量混为一谈，提出 FEB-30 基准通过范式反转直接检查记忆存储。

**核心贡献/观点**：
- 证明现有评估同时产生假阳性（正确回答掩盖坏记忆）与假阴性（错误回答怪罪好记忆）
- FEB-30 用 30 条事实演化轨迹覆盖 6 个诊断类别、3 个难度，提供确定性 ground truth
- 支持每次摄取步骤后直接检查记忆存储

**关键结果**：内在与外在评估平均分歧 16 个百分点，44% 轨迹超过有意义分歧阈值；记忆操作正确分类率仅 20%。
