## 今日概览

今日推荐的 10 篇论文主要聚焦于**工具学习与编码智能体的工程化**、**具身智能与机器人策略学习**、以及**基础模型与表征学习的统一化**三大前沿方向。

- **总体趋势**：今日论文呈现三条清晰主线——①「智能体的 RL 后训练」下沉到组件级：从工具调用的课程调度与门控奖励（MATCH）到编码 harness 的规划/动作空间/上下文管理拆解（Harness Design），再到用"观测监督"改进 RL 初始化（ActObs），都在把 Agent 的训练与工程推向可归因、可复用的层次；②「具身智能」的采样与动作生成优化：SGPS 用采样式 MPC 加速视觉策略学习，GeoAAC 用去噪轨迹几何做自适应动作分块，MILER 用语义中层表征做零样本 sim-to-real，共同指向更稳健、更高效的真实机器人策略；③「基础模型的统一表征」：SCGFM-ART 用关系图谱+摊销传输统一异构图，QUALS 用模式量化+可学习性同步平衡时序语料，Paint-Anything 用 hex-prompt 统一图像生成与编辑的颜色控制。
- **质量分布**：今日推荐论文评分在 8.00–9.47 之间，整体质量较高；前三篇（MATCH、Harness Design、SCGFM-ART）分别代表「方法范式创新」「实证组件归因」「理论严谨的统一表征」三个维度，均有清晰的理论或实证支撑。
- **研究热点**：
  - **工具学习与编码智能体的 RL 后训练**：MATCH 用能力边界课程 + 层级门控奖励闭环优化工具调用；Harness Design 用 176 组匹配消融拆解编码 harness 组件；ActObs 证明"监督观测 token"能显著改善后续 GRPO 探索。
  - **具身智能与 VLA 的动作生成**：GeoAAC 用 Flow Matching 去噪轨迹的几何信息做自适应动作分块；SGPS 用采样式 MPC 引导一阶策略优化；MILER 用语义 BEV 中层表征实现零样本 sim-to-real。
  - **基础模型的统一表示与数据效率**：SCGFM-ART 的关系图谱坐标统一异构图域；QUALS 的模式量化+可学习性同步提升时序预训练数据效率。
- **阅读建议**：建议优先阅读前三篇（MATCH → Harness Design → SCGFM-ART），它们分别代表方法范式、工程实证与理论统一三条主线；关注「智能体 RL 后训练」的读者可将第 1、2、4 篇连读；关注「具身智能」的读者可将第 5、6、10 篇连读，构成从视觉策略学习到真实部署的完整链条。

### [[MATCH_Model-Aware_Tool_Learning_with_Curriculum_Scheduling_and_Hierarchically_Gated_Rewards|MATCH: Model-Aware Tool Learning with Curriculum Scheduling and Hierarchically Gated Rewards]]
- **作者**：Shihao Liu, Hao Yin, Lijun Liu, Zhengzong Chen, Yuanyuan Zhao, Fei Huang
- **机构**：中国科学院大学、荣耀终端有限公司（Honor Device Co., Ltd）
- **链接**：[arXiv](https://arxiv.org/abs/2609.20082) | [PDF](https://arxiv.org/pdf/2609.20082)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/大语言模型/MATCH_Model-Aware_Tool_Learning_with_Curriculum_Scheduling_and_Hierarchically_Gated_Rewards|MATCH 详细分析]]

**一句话总结**：提出闭环框架 MATCH，用能力边界感知的课程调度（MACL）与层级门控奖励（HTGR）联合优化 LLM 工具调用，消除课程失配与参数级信用泄漏。

![[overview_3.png|600]]

**核心贡献/观点**：
- MACL 以奖励导出的难度实时追踪策略能力边界，每 epoch 选边界带 + top-k 困难池，替代固定阈值课程。
- HTGR 将工具名/参数键/参数值建模为门控链，逐级授予信用，从机制上消除可加性奖励的信用泄漏。
- 同一套 HTGR 奖励同时驱动 GRPO 更新与 MACL 难度刷新，形成优化—调度闭环。

**关键结果**：API-Bank 72.19%、BFCL V3 62.87%，超越监督式与 RL 式基线，跨四个骨干模型一致提升。

### [[An_Empirical_Study_of_Harness_Design_for_Coding_Agents|An Empirical Study of Harness Design for Coding Agents]]

- **机构**：UMass Amherst、Zoom、Emory University、UNC Charlotte

![[fig_harness_overview.png|600]]

**核心贡献/观点**：
- 固定执行循环、逐一变化三组件，实现编码 harness 的组件级因果归因。

### [[SCGFM-ART_Amortized_Relational_Transport_for_Structure-Centric_Graph_Foundation_Models|SCGFM-ART: Amortized Relational Transport for Structure-Centric Graph Foundation Models]]
- **作者**：Xiaodong He, Xincheng Wang, Zhao Kang
- **机构**：电子科技大学
- **链接**：[arXiv](https://arxiv.org/abs/2609.20419) | [PDF](https://arxiv.org/pdf/2609.20419)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/大语言模型/SCGFM-ART_Amortized_Relational_Transport_for_Structure-Centric_Graph_Foundation_Models|SCGFM-ART 详细分析]]

**一句话总结**：提出结构中心图基础模型 SCGFM-ART，用关系图谱（atlas）作为通用坐标系、ART 摊销式预测图-基传输，绕开运行时 GW 优化统一异构图域。

![[framework.png|600]]

**核心贡献/观点**：
- 关系图谱由有限关系基构成通用坐标系，ART 前馈预测图-基耦合（Sinkhorn 投影），免去逐样本 GW 外循环。
- 图表示分解为全局关系坐标 + 局部节点-角色对应，在单一接口内化解结构与语义双重异质性。
- 给出坐标保真度、稳定性、摊销覆盖三大理论界。

**关键结果**：14 个跨域任务图级/节点级平均排名 2.29/1.14，冻结目标域推理加速 44.2–85.1 倍。

### [[Don't_Mask_the_Environment_Observation_Supervision_Changes_How_Agents_Explore_Under_RL|Don't Mask the Environment: Observation Supervision Changes How Agents Explore Under RL]]
- **作者**：Juzheng Zhang, Disha Makhija, Manoj Ghuhan Arivazhagan, Vinayshekhar Bannihatti Kumar, Rashmi Gangadharaiah
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2609.20715) | [PDF](https://arxiv.org/pdf/2609.20715)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 ActObs，在 SFT 阶段同时监督轨迹中的观测 token（而非仅动作 token），让策略学会建模动作后果，显著改善后续 GRPO 探索。

**核心贡献/观点**：
- 打破"只对动作 token 做 SFT"的惯例，额外监督观测 token，不增加数据、参数、序列长度或前向开销。
- SFT 阶段动作与观测梯度会迅速正交，仅监督动作会留下大观测梯度残差并退化环境预测；联合监督可避免单向特化。
- 保留更多 RL 期熵、减少策略移动，最终策略更贴近 SFT 初始化。

**关键结果**：Qwen3-4B 上 GRPO pass@k 全预算优于仅动作基线；8B 上 pass@16 提升 +3.4pp；跨域 aider-polyglot pass@1 +4.2pp。

### [[MILER_Semantic_Mid-Level_Representation_for_Sim-to-Real_Reinforcement_Learning_in_Unstructured_Autonomous_Driving|MILER: Semantic Mid-Level Representation for Sim-to-Real RL in Unstructured Autonomous Driving]]
