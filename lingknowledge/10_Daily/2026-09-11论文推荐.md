## 今日概览

今日推荐的 10 篇论文主要聚焦于 **LLM 安全与对齐**、**长上下文推理与记忆**、**检索增强生成（RAG）效率优化** 和 **多模态视频理解** 等前沿方向。

- **总体趋势**：安全对齐从「静态防御」走向「动态机制理解」；长上下文推理与 RAG 两条线都开始强调「免训练 / 降成本 / 可并行」；多模态方向持续关注视频理解的效率瓶颈；低资源语言的文化偏见与智能体的自主学习能力也成为新热点。
- **质量分布**：今日推荐的论文评分在 8.67-9.60 之间，整体质量较高，前 3 篇均在 9.0 分以上。
- **研究热点**：
  - **LLM 安全防御机制**：从「是什么」深入到「为什么」，用优化动态揭示防御本质并反哺策略设计。
  - **长上下文与 RAG 的「去训练化」**：ConvMem（免训练卷积记忆）、LiteRAG（算法式探索替代 LLM 控制）共同指向降成本、可并行的趋势。
  - **多模态视频理解效率**：执法记录仪视频字幕与视频 LLM 推理效率综述，直击落地瓶颈。
- **阅读建议**：建议先读评分最高的前 3 篇（安全防御、长上下文推理、图检索），它们都已完成深度分析笔记；对多模态或智能体方向感兴趣的读者，可重点看 BodyCam-VQA 与 Task-Agnostic Environment Preprocessing。

### [[Active_Adaptation,_Not_Static_Defense_Temporal_Dynamics_of_Preventative_Steering_in_Adversarial_Fine-Tuning|Active Adaptation, Not Static Defense]]
- **作者**：Jing Guan, Yachao Yang, Zhaoliang Liu, Yuyao Zhang, Fanyu Meng, Junlan Feng
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2609.10142) | [PDF](https://arxiv.org/pdf/2609.10142)
- **来源**：arXiv
- **详细报告**：[[Active_Adaptation,_Not_Static_Defense_Temporal_Dynamics_of_Preventative_Steering_in_Adversarial_Fine-Tuning|Active Adaptation, Not Static Defense]]
- **笔记**：已有深度分析

**一句话总结**：揭示预防性引导（Preventative Steering）的持久保护源于「主动适应」而非静态防御，并据此提出渐进强度调度（PIS）提升 LLM 安全鲁棒性。

![[v7.drawio.png|600]]

**核心贡献/观点**：
- 从时间优化动态视角剖析 Preventative Steering：防御由早期补偿适应阶段 + 稳态阶段构成（纠正信号衰减）。
- 通过 IDP/IDP Continuation 实验证明：保留或重注入权重偏移无法维持保护，即「主动适应而非静态防御」。
- 提出 PIS（渐进强度调度），在 Qwen2.5 与 Gemma-3 上提升安全鲁棒性、降低有害特质表达。

**关键结果**：注意力输出投影是防御更新的主导残差写入路径；PIS 优于静态强度引导。

### [[ConvMem_Convolutional_Memory_for_Long-Context_Reasoning|ConvMem: Convolutional Memory for Long-Context Reasoning]]
- **作者**：Hongming Zhang, Zhaozhen Gu, Fengshuo Bai, Ming Hao, Qingyang Zhang, Yuanyuan Wang, Shiyang Tang, Yanna Wang, Bo Xu
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2609.10441) | [PDF](https://arxiv.org/pdf/2609.10441)
- **来源**：arXiv
- **详细报告**：[[ConvMem_Convolutional_Memory_for_Long-Context_Reasoning|ConvMem: Convolutional Memory for Long-Context Reasoning]]
- **笔记**：已有深度分析

**一句话总结**：提出免训练、高度可并行的 ConvMem 框架，将长上下文推理重构为层次化卷积，把线性推理链压缩为对数树。

![[2609.10441_fig1.png|600]]

**核心贡献/观点**：
- 将「带特定查询的 LLM」视为卷积核，对文本段做层次化总结，免训练、可并行。
- 集成可配置步长 + 跳跃连接 + 多核卷积，稳健捕获证据并缓解误差累积。
- 在 RULER-HotpotQA / RULER-2WikiMultiHopQA 上优于免训练基线，避免 RL 过拟合风险。

**关键结果**：训练自由、大规模并行，长上下文多跳 QA 表现优于免训练基线。

### [[LiteRAG_Cost-Efficient_Graph-Based_Retrieval-Augmented_Generation|LiteRAG: Cost-Efficient Graph-Based RAG]]
- **作者**：Daniel Alejandro Coll Tejeda, Pedro García López, Daniel Barcelona-Pons
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2609.10239) | [PDF](https://arxiv.org/pdf/2609.10239)
- **来源**：arXiv
- **详细报告**：[[LiteRAG_Cost-Efficient_Graph-Based_Retrieval-Augmented_Generation|LiteRAG: Cost-Efficient Graph-Based RAG]]
- **笔记**：已有深度分析

**一句话总结**：LiteRAG 用查询条件化的算法式探索替代检索期 LLM 控制，在保持最高质量的同时把延迟降 100×、成本降 99%。

![[architecture_compact.png|600]]

**核心贡献/观点**：
- 以确定性算法（查询自适应阈值 + 社区感知中心节点惩罚）替代检索期 LLM 控制。
- 沿推理链构建紧凑上下文，避免弥散超长上下文降低生成效率。
- DistComp 最高质量（0.798）+ 延迟/成本骤降；UltraDomain 以 14× 更少 token 匹配 LinearRAG。

**关键结果**：质量与效率兼得，为 GraphRAG 生产部署扫清成本障碍。

### Multilingual in Name Only? Cultural and Linguistic Weaknesses of LLMs in Urdu
- **作者**：Farah Adeeba, Abdul Rafae Khan, Rajesh Bhatt, Hassan Sajjad
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2609.10758) | [PDF](https://arxiv.org/pdf/2609.10758)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：系统评估低资源语言乌尔都语的 LLM 生成质量，发现其存在基本语法/语义错误与文化浅薄问题。

**核心贡献/观点**：
- 构建 Urdu-Stories 语料（93 个故事，3 个当代 LLM 生成），九标签语言/语义/文化错误分类。
- 发现 LLM 常犯基本语法语义错误，故事缺乏连贯性、重复不自然、文化浅薄。
- few-shot 提示无法显著解决文化与上下文错误。

**关键结果**：揭示 LLM 作为低资源语言内容生成与信息检索来源的局限性。
