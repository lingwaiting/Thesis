## 今日概览

今日推荐的 10 篇论文主要聚焦于 **强化学习与智能体**、**LLM 推理与自纠错** 和 **机器人世界模型** 三大前沿方向。

- **总体趋势**：今日论文呈现两条清晰主线——一是"强化学习的信用分配与智能体训练"（解释性世界模型 EWM、匹配上下文 GPO、Rollout-Time Intervention、SafeDiSTL、MARGoS）；二是"LLM 推理的自我纠错与蒸馏"（UPTURN 测试时纠错、批判条件自蒸馏）。此外，D2R 代表机器人策略的持续学习，UkrMeme 代表多模态说服检测，首篇多智能体调优框架则展示了 LLM 向专业神经网络自动化的延伸。
- **质量分布**：今日推荐的论文评分在 8.37-10.13 之间，整体质量优秀。前 3 篇（评分 9.33+）兼具新颖选题与扎实方法，且均已配图并生成深度分析，尤其值得精读。
- **研究热点**：
  - **长时程信用分配**：从 EWM 的"解释驱动奖励重分配"到 MCGPO 的"匹配上下文动作偏好"、RTI 的"rollout 干预"，多个工作从不同角度攻克 RL/agent 训练中的信用分配难题。
  - **LLM 推理自纠错**：UPTURN 的"新用户轮注入"与批判条件自蒸馏共同揭示——让模型"定位错误并转向"比"生成修订"更关键。
  - **机器人世界模型与持续学习**：D2R 用冻结世界模型"想象复述"旧任务，实现机器人策略的无遗忘持续学习。
- **阅读建议**：建议先读评分最高的前 3 篇（多智能体调优、UPTURN 推理纠错、EWM 信用分配），它们分别代表 LLM 自动化、推理自纠错、长时程 RL 三个方向的前沿；再按兴趣跟进智能体训练方向（MCGPO、RTI、SafeDiSTL）或机器人持续学习方向（D2R）。

### [[A_Multi-Agent_LLM_System_for_Automated_Tuning_of_Specialized_Neural_Network_Models|A Multi-Agent LLM System for Automated Tuning of Specialized Neural Network Models]]
- **作者**：Ivan Moloshnikov, Dmitry Kunitsyn, Alexander Sboev, Maksim Skorokhodov, Roman Rybka, Yuanchao Liu
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2610.13663) | [PDF](https://arxiv.org/pdf/2610.13663)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/大语言模型/A_Multi-Agent_LLM_System_for_Automated_Tuning_of_Specialized_Neural_Network_Models|详细分析]]

**一句话总结**：提出三角色（分析师/编码器/记录员）多智能体 LLM 框架，在"只改组件、不改结构"的语义狭窄空间内自动调优专用神经网络，跨脉冲分类与 PINN 两类异构任务均显著提升。

![[2610.13663_fig1.png|600]]

**核心贡献/观点**：
- 把组件级调优形式化为"开放但语义狭窄"的代码生成问题，只针对指定组件生成代码、保持网络整体结构不变
- 三角色分工 + 实验日志 + 沙箱执行构成可追溯、可复现的迭代闭环
- 同一框架无需改动即可跨脉冲神经网络与物理信息网络两类性质迥异的模型迁移

**关键结果**：MNIST 准确率 +13pp、Digits +6pp；GNLSE 单孤子解误差降约 2491 倍、不变量保持误差降约 325 倍；KS 问题质量漂移降 14 倍。

### [[Inject_a_Turn,_Not_a_Token_Learning_Where_to_Redirect_LLM_Reasoning_for_Self-Correction|Inject a Turn, Not a Token: Learning Where to Redirect LLM Reasoning for Self-Correction]]
- **作者**：Jiwon Jeon, Myungsik Cho, Jeonghye Kim, Youngchul Sung
- **机构**：韩国科学技术院（KAIST）
- **链接**：[arXiv](https://arxiv.org/abs/2610.13672) | [PDF](https://arxiv.org/pdf/2610.13672)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/大语言模型/Inject_a_Turn,_Not_a_Token_Learning_Where_to_Redirect_LLM_Reasoning_for_Self-Correction|详细分析]]

**一句话总结**：提出 UPTURN，用 130K 参数 MLP 头学习"干预位置"，并以"新用户轮"注入重定向指令，在无需微调 LLM 的情况下可靠地纠错推理。

![[2610.13672_fig1.png|600]]

**核心贡献/观点**：
- 将自我纠错解耦为"在哪干预"（位置学习）与"如何重定向"（轮次注入）两个正交问题
- 仅用最终答案正确性这一弱信号训练轻量 MLP 头定位错误，无需 token 级监督
- 实证发现"新用户轮注入"优于"行内 token 注入"，能更可靠地改变模型轨迹

**关键结果**：4 个推理器 × 6 个数学基准全部提升平均准确率；超越 self-correction 与 reflection-token 注入基线；零微调迁移到 GPQA-Diamond；与 GRPO 互补。

### [[Beyond_Temporal_Proximity_Explanatory_World_Models_for_Credit_Assignment_in_Reinforcement_Learning|Beyond Temporal Proximity: Explanatory World Models for Credit Assignment in Reinforcement Learning]]
- **作者**：Oriol Corcoll, Qiyao Wei, Ciarán Mark Gilligan-Lee
- **机构**：Spotify / 剑桥大学
- **链接**：[arXiv](https://arxiv.org/abs/2610.13504) | [PDF](https://arxiv.org/pdf/2610.13504)
- **来源**：arXiv
- **笔记**：[[20_Research/Papers/强化学习与智能体/Beyond_Temporal_Proximity_Explanatory_World_Models_for_Credit_Assignment_in_Reinforcement_Learning|详细分析]]

**一句话总结**：提出解释性世界模型（EWM），用前沿 LLM 的解释识别对结果有贡献的早期事件，并按相关性（而非时间邻近性）重分配奖励，解决长时程信用分配问题。

![[2610.13504_fig1.png|600]]

**核心贡献/观点**：
- 用 LLM 解释作为奖励重分配的归因信号，把信用从"时间邻近"改为"因果相关"
- 保守层次算子递归重分配奖励且保持无折扣 episode 回报守恒，可直接嵌入现有 RL 流程
- 具体化三种解释变体（Halpern 实际因果、Lombrozo 简洁性、Deutsch 难变性）

**关键结果**：Crafter/WordCraft 大幅超越 PPO/LaRe（延迟越大增益越大）；KuaiRand 超 SFT/LaRe（离线）与 A2C（在线）；工业生成式推荐 Recall 显著提升。

### Dream to Remember: Continual Steering of Generalist Robot Policies with World Models
- **作者**：Bahey Tharwat, Iman Nematollahi, Marvin Alles, Xingyuan Zhang, Akshay L Chandra, Abhinav Valada
- **机构**：弗莱堡大学 / 慕尼黑工业大学
- **链接**：[arXiv](https://arxiv.org/abs/2610.13816) | [PDF](https://arxiv.org/pdf/2610.13816)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 D2R，用冻结世界模型通过"想象 rollout"复述旧任务，让通用机器人策略在连续学习新任务时不遗忘旧技能。

**核心贡献/观点**：
- 在 steering 模块学习新任务时，用冻结的预训练世界模型通过想象 rollout 复述旧任务，锚定模块的早期行为
- 世界模型足够忠实时，可完全在想象中学习新任务；否则在环境中学习、仅用世界模型复述旧任务
- 无需 replay buffer 或新数据，解决顺序任务中的灾难性遗忘

**关键结果**：CALVIN 上纯想象连续学 8 个任务，平均成功率 63.7%→74.8%（LoRA 微调同序列跌至 11.7%）；π₀+A2World 上学会未见 LIBERO-90 任务；真实 Franka 上连续学 3 个任务并保留早期提升。

### A Privileged Teacher That Only Scores Cannot Search: Critique-Conditioned On-Policy Self-Distillation for Reasoning
- **作者**：Mayug Maniparambil, Ayush Rai, Ekansh Verma, Noel E. O'Connor, Fergal Reid
- **机构**：Fin.ai / 都柏林城市大学
- **链接**：[arXiv](https://arxiv.org/abs/2610.13744) | [PDF](https://arxiv.org/pdf/2610.13744)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：证明"仅打分"的教师无法定位推理错误，提出批判条件自蒸馏——先让教师生成批判，再以此条件化打分教师，使信号能定位错误并引导回溯。

**核心贡献/观点**：
- 用金标准错误跨度测试自蒸馏目标的两种信号，发现它们既不能定位错误、也不能把概率推离错误 token
- 论证该失败是结构性的：定位错误本身是搜索问题，而"仅打分"的教师从未被要求做搜索
- 批判条件化后，信号能定位错误、推动概率转向"Wait/But/Actually"等回溯 token

**关键结果**：测试时用批判可把采样无法解出的数学题转正；在 cold-start GRPO 中为原本无优势信号的提示提供优势信号。

### SafeDiSTL: Decomposing Joint Constraints for Safe Multi-Agent Reinforcement Learning
- **作者**：Hongrui Zheng, Aditya Singh, Rahul Mangharam
- **机构**：宾夕法尼亚大学
- **链接**：[arXiv](https://arxiv.org/abs/2610.13737) | [PDF](https://arxiv.org/pdf/2610.13737)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 SafeDiSTL，用信号时序逻辑（STL）鲁棒性度量 + 动作敏感性在"联合约束测量"下实现信用分配，解决安全多智能体 RL。

**核心贡献/观点**：
- 用 STL 鲁棒性通过 running-maximum 代价增量度量 episode 级违规，并借助可微动力学得到动作敏感性
- 动作敏感性把每个代价增量在同决策时刻分配到各智能体，并计入延迟效应
- 在仅有团队级联合约束测量时，仍能区分各智能体对违规的贡献

**关键结果**：协同运输安全成功率 1.6-5.1×、导航安全成功率 +11.1%、交通吞吐 +50-68%（对比约束基线）。

### Rollout-Time Intervention: Unlocking Agentic Reinforcement Learning Beyond Policy Limits
- **作者**：Xi Chen, Ruixue Ding, Zhigaoyuan Wang, Fanrui Zhang, Qiang Zhang, Boli Chen, Shihang Wang, Tianfu Wang, Ailin Ren, Pengyong Wang, Pengjun Xie, Hui Xiong
- **机构**：阿里巴巴 Token Hub / 高德 / 港科大（广州）
- **链接**：[arXiv](https://arxiv.org/abs/2610.13438) | [PDF](https://arxiv.org/pdf/2610.13438)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 RTI，在 rollout 阶段利用奖励侧证据（评估 rubrics）把错误轨迹转为成功轨迹，突破智能体 RL 的 on-policy 推理瓶颈。

**核心贡献/观点**：
- 定位智能体 RL 的 on-policy 推理瓶颈：任务超出当前能力边界时有效轨迹极稀疏、训练易塌缩
- 在 rollout 时用评估 rubrics 把错误轨迹纠正为成功轨迹，为策略很少独立解出的任务提供学习信号
- 干预轨迹本质是 off-policy，但过滤掉分布偏移过大的轨迹后仍能有效引导策略优化

**关键结果**：5 个基准上持续超越 RL 基线；后训练策略接近更强 LLM，并超越原有能力边界；代码开源。
