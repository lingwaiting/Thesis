## 今日概览

今日推荐的 10 篇论文主要聚焦于 **LLM 推理与对齐**、**多模态 VLM Agent** 和 **Agentic RAG** 等前沿方向。

- **总体趋势**：本月论文呈现出三个明显转向：(1) 从"训练时优化"转向"推理时优化"——多篇论文探索无需训练的推理增强方法；(2) 对齐研究从"浅层安全"向"深层结构安全"深化，揭示了 RLHF 对齐的结构性脆弱性；(3) VLM Agent 从简单工具调用升级为"主动想象+世界建模"的认知架构。
- **质量分布**：今日推荐的论文评分在 6.8-8.5 之间，整体质量较高，多篇来自顶级机构（CMU、阿里巴巴、北大）或被顶会接收（ICML 2026 Workshop、ACL 2026、UAI 2026）。
- **研究热点**：
  - **推理时自适应优化**：ReContext（递归证据重放）、C3RL（置信度校准推理）、Confident Layer Decoding（中间层解码）三篇从不同角度优化推理效率
  - **对齐的结构性脆弱性**：RLHF 浅层对齐、推理模型对齐退化、生成轨迹安全——对齐研究正从"表面合规"走向"深层稳健"
  - **VLM Agent 认知架构升级**：Astra 引入世界模拟器、PRPO 解决感知 Credit Assignment、Goal2Pixel 统一像素级 VLM 导航
- **阅读建议**：建议从 LLM 推理优化的三篇（#1 ReContext、#2 C3RL、#6 Confident Layer Decoding）入手，理解推理时优化的技术路线；再读对齐安全方向（#3 Does Reasoning Preserve Alignment、#9 Agent Safety），把握安全研究的深层趋势；最后深入多模态 Agent 方向（#4 Astra、#5 PRPO）。

### [[PRPO_Perception-Reinforced_Policy_Optimization_via_Token-Level_Dynamic_Advantage_Reshaping|PRPO: Perception-Reinforced Policy Optimization via Token-Level Dynamic Advantage Reshaping]]
- **作者**：Qiming Li 等（阿里巴巴集团、北京大学）
- **机构**：阿里巴巴集团、北京大学
- **链接**：[arXiv](https://arxiv.org/abs/2606.08708) | [PDF](https://arxiv.org/pdf/2606.08708)
- **来源**：arXiv (2606.08708)
- **日期**：2026-06-07
- **推荐评分**：7.6
- **笔记**：--

**一句话总结**：解决多模态 RL 中的感知 Credit Assignment 问题——关键感知 token 被大量推理 token 稀释，提出 RVD+PAR 方法在 token 级别重新分配 credit。

**核心贡献/观点**：
- 识别并定义了**感知 Credit Assignment 问题**：在标准轨迹级奖励下，关键的感知 token 信号被海量推理 token 稀释
- 提出 **RVD（鲁棒视觉依赖）**：识别基于视觉证据且在扰动下鲁棒的 token
- 提出 **PAR（感知优势重塑）**：在 token 级别放大感知 token 的 credit
- 在 7 个多模态推理基准上，3B 规模平均提升 23.3%，7B 规模提升 21.1%

**关键结果**：Token 级别的动态优势重塑使多模态 RL 训练更高效，在多个基准上达到 SOTA 性能。

### [[Deeper_is_Not_Always_Better_Mitigating_the_Alignment_Tax_via_Confident_Layer_Decoding|Deeper is Not Always Better: Mitigating the Alignment Tax via Confident Layer Decoding]]
- **作者**：--
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2606.21906) | [PDF](https://arxiv.org/pdf/2606.21906)
- **来源**：arXiv (2606.21906)
- **日期**：2026-06-20
- **推荐评分**：7.4
- **笔记**：--

**一句话总结**：揭示 LLM 层间的 Guess-Refine-Perturb 动态，提出 Confident Decoding 在中间层提前解码以绕过对齐扰动，在 Omni-MATH 上提升 22.4%。

**核心贡献/观点**：
- 发现 LLM 层间存在 **Guess-Refine-Perturb** 三阶段动态：先猜测、再精炼、最后因对齐而扰动
- 提出 **Confident Decoding**：在模型对答案足够自信的中间层提前停止并解码
- 动态选择解码层以绕过深层对齐带来的性能扰动
- 延迟开销不到 2%

**关键结果**：Confident Decoding 在 Omni-MATH 上取得 +22.4% 的提升，以极低的计算开销同时改善了推理能力和对齐效果。
