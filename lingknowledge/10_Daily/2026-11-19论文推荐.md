## 今日概览

今日推荐的 10 篇论文主要聚焦于**大语言模型高效部署与微调**、**世界模型驱动的智能体决策**和**多模态 agentic 推理**等前沿方向。

- **总体趋势**：今日推荐呈现三条清晰主线——(1) LLM 后训练与部署的「自动化/数据高效化」：用 agent 自动设计量化方案、用温度匹配做数据高效微调；(2) 「冻结世界模型」的能力挖掘：把世界模型当作评价器/滤波器，在决策侧用极小参数做轻量 RL 或自校正；(3) agentic/多模态推理的效率与可靠性：speculative 推理加速、注意力 sink 利用、推理轨迹可解释性。
- **质量分布**：今日推荐的论文评分在 8.53-10.8 之间，整体质量较高，前三篇均超过 10 分，属于兼具创新性与工程价值的实用工作。
- **研究热点**：
  - **LLM 量化自动化**：QDA 用 agent 闭环设计量化方案，将评估成本从数十 GPU-hours 压到分钟级。
  - **数据高效微调**：Ambient SFT 用温度匹配统一 SFT 与知识蒸馏，数据稀缺时最高 +21%。
  - **冻结世界模型**：Residual-Guided RL 与 Self-Correcting Visual Planning 同期探索「不训练世界模型、只训练决策侧」的范式。
- **阅读建议**：建议先读前三篇（QDA → Residual-Guided RL → Ambient LLMs），把握「LLM 部署自动化」与「世界模型决策」两大主线；再按兴趣选读 SpecLook（推理加速）、BOS Summary（注意力机制）、Nunchi（多模态）等。

### [[20_Research/Papers/强化学习与智能体/Residual-Guided_Lightweight_Reinforcement_Learning_for_Risk-Aware_Trajectory_Selection_with_a_Frozen_World_Model|Residual-Guided Lightweight RL for Risk-Aware Trajectory Selection]]
- **作者**：Jiaqi Wu, Yongqi Dong, Yijie Zhong, Maple Shao, Yide Tao, Linsen Cai, Weize Cai, Hai L. Vu, Alvaro Garcia Hernandez
- **机构**：RWTH Aachen University；Monash University
- **链接**：[arXiv](https://arxiv.org/abs/2611.22998) | [PDF](https://arxiv.org/pdf/2611.22998)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/强化学习与智能体/Residual-Guided_Lightweight_Reinforcement_Learning_for_Risk-Aware_Trajectory_Selection_with_a_Frozen_World_Model|Residual-Guided Lightweight RL]]

**一句话总结**：在冻结的世界模型上，用 PPO 微调「候选选择 + 有界轨迹残差」的联合策略，部署时仅保留 ~11.7K 参数的排序网络，实现场景自适应的轻量轨迹选择。

![[architecture_dimensions_20261115_page1.png|600]]

**核心贡献/观点**：
- 提出残差引导的轻量强化学习框架，训练期更新 16,106 参数，部署仅保留 11,725 参数的 ranking network。
- context-conditioned ranking network 从「局部扰动反馈」中学习候选偏好，推理时用固定权重融合学习偏好与预测风险排名。
- 证明冻结世界模型可作为轻量 RL 的「评价器」，残差分支与 critic 仅用于训练。

**关键结果**：nuScenes 验证集上，平均欧氏轨迹误差（L2）相对 RiskWorld 基线降低 3.99%；残差探索相对 categorical PPO 再降 0.83%；风险特征移除/打乱时仍保持更优。

### [[20_Research/Papers/大语言模型/QDA_Closed-Loop_LLM_Quantization_Design_with_Agents|QDA: Closed-Loop LLM Quantization Design with Agents]]
- **作者**：Xingyang Li, Tianlang Zhao, Song Han, Ligeng Zhu
- **机构**：MIT；NVIDIA
- **链接**：[arXiv](https://arxiv.org/abs/2611.23388) | [PDF](https://arxiv.org/pdf/2611.23388)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/QDA_Closed-Loop_LLM_Quantization_Design_with_Agents|QDA]]

**一句话总结**：让 LLM agent 通过「构建候选 + KL 散度快速评估 + 长生成检查」的闭环自动为每个模型和精度设计量化方案，用 64 GPU-hours/搜索超越最强公开方案。

![[fig1-teaser-qda_page1.png|600]]

**核心贡献/观点**：
- 用输出 KL 散度（在 agent 未见过的推理轨迹上）做分钟级代理评估，打通 agent 自动化搜索。
- 长生成检查捕获重复循环等失败模式；配套相互兼容、兼容新架构的公开 PTQ 方法库。
- 所有 QDA checkpoint 可直接在现有 serving 内核运行，零推理开销。

**关键结果**：四个推理模型上相对最强公开方案平均提升 0.9/1.4/2.2 pp（W4A16/W4A8/W3A16）；320B MoE 模型 GLM-5.3-Flash 在 NVFP4 W4A4 恢复 98.3% FP8 精度（vs 96.9% vendor 最佳）。

### [[20_Research/Papers/大语言模型/Ambient_LLMs_Data-Efficient_Supervised_Fine-tuning_via_Temperature_Matching|Ambient LLMs: Data-Efficient SFT via Temperature Matching]]
- **作者**：Giannis Daras, Marios Papachristou, Adam Klivans, Antonio Torralba, Constantinos Daskalakis
- **机构**：Arizona State University；University of Texas at Austin
- **链接**：[arXiv](https://arxiv.org/abs/2611.23229) | [PDF](https://arxiv.org/pdf/2611.23229)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/Ambient_LLMs_Data-Efficient_Supervised_Fine-tuning_via_Temperature_Matching|Ambient LLMs]]

**一句话总结**：用冻结的预训练模型作为噪声教师，通过「高温条件分布匹配」正则化 SFT，在数据稀缺时显著缓解过拟合与尾部遗忘。

![[method-overview_page1.png|600]]

**核心贡献/观点**：
- 提出 Ambient SFT 框架，用温度 $T$ 作为控制对预训练模型信任度的连续旋钮（$T\to\infty$ 回退标准 SFT，$T=1$ 回退知识蒸馏）。
- 把 SFT 与知识蒸馏统一到「温度匹配」这一原理性框架下。
- 数据越稀缺，相对标准 SFT 的优势越显著。

**关键结果**：在域适应、指令微调、推理三类任务上全面优于标准 SFT，最高达 21% 平均相对提升。

### SpecLook: Speculating Where to Look for Fast and Reliable Agentic MLLMs
- **作者**：Xi Ding, Jiawei Zhang
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.23483) | [PDF](https://arxiv.org/pdf/2611.23483)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：通过「推测 agent 的下一次观察（glimpse）」而非推测答案，实现无需训练的 speculate-and-verify 框架，显著加速带图思考的 agentic 多模态大模型推理。

**核心贡献/观点**：
- 三层 speculate-and-verify：小模型先草拟观察并重答，若答案不变且置信则结束；否则大模型无需工具即验证纠正 glimpse 并融合答案。
- 每个答案都附带无标签的可信度评分；SpecLook-Fast 跳过最终 forward pass，无问题需跑完整循环。

**关键结果**：在 V*、HR-Bench、POPE 上均超越所有基线；SpecLook 达 87.2%/86.2% 平均精度，相对 DeepEyes-7B 和 Thyme-RL agent 分别 7.7×/4.7× 加速。

### Runtime Verification of Multiple Natural Language Criteria for Agent Governance
- **作者**：Silviu Pitis, Parand A. Alamdari, Jessica Tang, Toryn Q. Klassen, Sheila A. McIlraith
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.23074) | [PDF](https://arxiv.org/pdf/2611.23074)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出树注意力验证器 VFM，可并行对数百条自然语言准则给出「满足/违反/不适用」三元判决，用于 AI agent 的运行时治理。

**核心贡献/观点**：
- 编码共享上下文与目标文本，并行对 N 条准则打分，返回独立的逐准则三元判决。
- 在 CriteriaBank（394K 三元组、321K 不同准则）上预训练，VFM-4B 在合成治理基准上超越 GPT-5.4。
- 逐准则判决可定位被违反的规则，支持聚焦升级到更大的 CoT 判断器。

**关键结果**：单张 H100 上 VFM-4B 在 <2s 内评估 1000 条准则（4K-token 上下文），显存 <11GB。

### BOS Summary: The First Token Matters
- **作者**：Hui Zhu, Saleh Zare Zade, Rafi Ibn Sultan, Deng Pan, Arun Ross, Dongxiao Zhu
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.23508) | [PDF](https://arxiv.org/pdf/2611.23508)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：无需训练地在单层 prefill 阶段松开 BOS token 的因果约束，让它聚合全部输入形成自派生上下文表征，从而把「注意力 sink」转化为有用的上下文载体。

**核心贡献/观点**：
- 仅对 BOS 查询行放宽因果约束，BOS 聚合所有视觉与文本输入，其余 token 保持标准因果注意力。
- 无额外参数、无辅助模块、无解码期开销。
- 机制分析表明让 BOS 输入特异化会削弱其 sink 主导地位，把注意力重新分配到承载内容的 token。

**关键结果**：跨多个 VLM/LLM 家族与 8 个多模态/纯文本基准，优于直接/CoT 提示，并在多步推理上超越近期 sink 干预方法。

### What's in a Tree? Hierarchical $n$-gram models as controlled approximators of language
- **作者**：Aritra Das, Francesco Cagnetta, Darshil Doshi, Victor V. Albert, Maissam Barkeshli, Andrey Gromov
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.23093) | [PDF](https://arxiv.org/pdf/2611.23093)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出「tree-grams」——一种分层组合 order-2/order-3 张量的自回归 n-gram 模型，作为可控、可解释、可系统扩展的语言近似器，性能超越传统 n-gram 并逼近深度 transformer。

**核心贡献/观点**：
- $n$ 控制最大上下文窗口，rank 超参 $d$ 控制容量，形成可解释且可系统扩展的语言近似器家族。
- 用 tree-grams 做生成模型，在 $\mu$P 下超参迁移更稳健。
- 路由候选拓扑时涌现稀疏性，可剪枝 95% 拓扑而无明显性能损失。

**关键结果**：tree-grams 超越现有 n-gram 基线，并与深度 transformer 语言模型保持竞争力。

### How Uncertain Is My Action? Self-Correcting Visual Planning with Frozen World Models
- **作者**：Siqing Li, Luming Yang, Yijia Jiao, Junze Deng, Alper Yilmaz
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.23620) | [PDF](https://arxiv.org/pdf/2611.23620)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：让冻结的潜在世界模型「反向运行」以量化动作接口的不确定性，实现视觉规划器的自校正，无需训练即可检测并补偿执行偏差。

**核心贡献/观点**：
- 对任意假设的执行偏移，模型反向预测「应该观察到什么」，与真实观察对比即可量化偏移并让规划器自我校正。
- 「shift score」只保留残差中可由偏移产生的部分，优于混合模型误差的残差能量。
- 检测符合预测（0.05 AUROC 内），用 Cramer-Rao 误差棒估计偏移并命名主导生成器。

**关键结果**：PushT 成功率从 0.650 提升到 0.862，Cube 从 0.378 到 0.432；真实机械臂上把 36mm 末端误差降到 3-5mm。

### Nunchi: Ears Help Eyes in Multi-Party Conversations
- **作者**：JunYeong Park, Shijing Wang, Seonwook Park, Michael Stengel, Shalini De Mello, Sang-Il Choi, Hyung Jin Chang
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.23115) | [PDF](https://arxiv.org/pdf/2611.23115)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出多模态框架 Nunchi，将语音/说话者等会话线索与视线几何结合，让 VLM 在多说话人场景中准确判断「谁在看谁」。

**核心贡献/观点**：
- 引入 SORBET 基准：3,340 样本、1,578 片段，含同步语音、转写与关注对象标签，覆盖更多多说话人场景。
- Nunchi 从转写与视线/说话人模型输出构建文本提示，用共享标签把每条线索关联到候选人物，由 VLM 权衡视线几何与会话线索。
- 会话线索有效，而额外视觉线索无效，且增益跨三个 VLM 稳定。

**关键结果**：相对最强现有方法提升 4.8 个百分点；在 SORBET 及两个现有数据集上均有效，且兼容自动转写。
