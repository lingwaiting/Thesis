## 今日概览

今日推荐的 10 篇论文主要聚焦于**高效大模型推理**、**具身智能体与机器人学习**和**多智能体强化学习与安全**等前沿方向。

- **总体趋势**：今日论文呈现「效率」与「智能体」双主线——前者致力于把大模型做小做快（稀疏 MoE 的 Stepped MoE、混合精度量化的 AlignQuant），后者致力于把智能体做强做稳（机器人视频上下文学习的 RV-ICL、分层世界模型的 H-JEPA、共享约束责任分配的 LiRA）；同时，LLM 安全（PEV 越狱）与数据基础设施（CroissantMiner）持续受到重视。
- **质量分布**：今日推荐的论文评分在 9.07–10.0 之间，整体质量很高，其中 Stepped MoE（弹性×稀疏统一）、AlignQuant（tile 对齐量化）、RV-ICL（演示视频即层级）三条线均有明确且可落地的创新点。
- **研究热点**：
  - **稀疏 MoE 与弹性架构**：Stepped MoE 将「弹性容量」与「输入自适应稀疏」统一到单一 backbone，实现一次训练、多容量部署。
  - **GPU 对齐的混合精度量化**：AlignQuant 以二维权重 tile 对齐精度分配/存储/执行，把压缩真正兑现为 2.5× 生成加速。
  - **具身智能体与世界模型**：RV-ICL 用可导航视频层级做 one-shot 机器人演示，H-JEPA 用分层 JEPA 做长时程视觉规划。
- **阅读建议**：建议先读工程实用价值最高的 **Stepped MoE** 与 **AlignQuant**（了解大模型高效推理的「弹性×稀疏」与「tile 对齐量化」两大方向），再读具身智能方向的 **RV-ICL**（one-shot 机器人演示，training-free），最后按兴趣深入世界模型（H-JEPA）、多智能体约束（Who Bears the Burden）或 LLM 安全（PEV 越狱）。

### [[Stepped_MoE_Segment-Level_Routing_with_Configurable_Inference_Complexity|Stepped MoE: Segment-Level Routing with Configurable Inference Complexity]]
- **作者**：Arnav Kundu, Zhaoyang Xu, Bairu Hou, Chang Gao, Reed Li, Tao Lei
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2610.07348) | [PDF](https://arxiv.org/pdf/2610.07348)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/Stepped_MoE_Segment-Level_Routing_with_Configurable_Inference_Complexity|Stepped MoE 详细分析]]
- **笔记**：已生成详细分析

**一句话总结**：提出统一框架，将「弹性结构」与「稀疏门控架构」结合，让单个 LLM 在推理时既按部署约束缩放容量、又按输入难度自适应路由，跨 1–4B 多个容量点。

![[arch_new.png|600]]

**核心贡献/观点**：
- 首次统一「弹性容量」与「输入自适应稀疏」两大维度，以「段级路由」耦合进单一 backbone。
- backbone 以「上下文 + 目标效率规格」为条件，实现精度-效率权衡的细粒度控制。
- 弹性嵌套子网络内激活任务相关参数，参数共享显著节省设备端磁盘空间。

**关键结果**：比同容量 dense 模型在知识密集型基准上准确 2–5%，与静态稀疏版持平，延迟与 dense 模型相近。

### [[Recursive_Video_In-Context_Learning_for_Agentic_Robot|Recursive Video In-Context Learning for Agentic Robot]]

**一句话总结**：提出训练无关的 RV-ICL，把一条演示视频组织成 agent 可递归导航的层级，在规划阶段读粗粒度、执行阶段按需加载接触点附近的细粒度片段。

### [[AlignQuant_Tile-Aligned_Mixed-Precision_Quantization_for_Efficient_LLM_Generation|AlignQuant: Tile-Aligned Mixed-Precision Quantization for Efficient LLM Generation]]
- **作者**：Hanzhi Zhang, Qiao Zhang, Qinglei Cao, Heng Fan, Yan Huang, Kewei Sha, Yunhe Feng
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2610.07457) | [PDF](https://arxiv.org/pdf/2610.07457)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/AlignQuant_Tile-Aligned_Mixed-Precision_Quantization_for_Efficient_LLM_Generation|AlignQuant 详细分析]]
- **笔记**：已生成详细分析

**一句话总结**：以 GPU 兼容的二维权重 tile 作为精度分配、紧凑存储与执行的共同单元，让混合精度量化的局部精度灵活性与规则 GPU 执行共存。

![[framework_page1.png|600]]

**核心贡献/观点**：
- 「tile 对齐」统一精度分配/存储/执行三粒度，消除精度边界与硬件边界的失配。
- prefill/decode 联合校准 + phase-normalized 分数，按阶段敏感度优先分配精度。
- phase-specialized kernels 复用打包模型、展开为 INT8 计算，兼顾存储紧凑与计算规则性。

**关键结果**：在 4 个 3B–14B LLM 上最高实现 2.50× 生成加速（相对 BF16）且保持质量，覆盖 3 种 GPU、最长 64K 上下文。

### [[Who_Bears_the_Burden_Learning_Responsibility_for_Shared_Constraints_in_Multi-Agent_Reinforcement_Learning|Who Bears the Burden? Learning Responsibility for Shared Constraints in Multi-Agent RL]]
- **作者**：Xiaoyang Cao, Jingqi Li, Zhe Fu, Alexandre M. Bayen
- **链接**：[arXiv](http://arxiv.org/abs/2610.07491) | [PDF](https://arxiv.org/pdf/2610.07491)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 LiRA，学习每个智能体对共享约束乘子的「责任份额」，在保持总预算约束的前提下优化多智能体系统的社会福利。

**核心贡献/观点**：
- 用「责任份额」重新分配共同乘子的影响力，不改动原始奖励或约束。

**关键结果**：在 CityLearn、MABIM、Harvest、MetaDrive（3–400 个智能体）上，平均社会福利较均匀/个体乘子基线提升最高 29%，网格与驾驶成本保持预算内。

### [[Jailbreaking_Open-Weight_LLMs_via_Random_Embedding_Perturbations|Jailbreaking Open-Weight LLMs via Random Embedding Perturbations]]
- **作者**：Abhinav Sudhakar Dubey, Scott Sirri, Vaggos Chatziafratis, C. Seshadhri
- **机构**：University of California Santa Cruz
- **链接**：[arXiv](http://arxiv.org/abs/2610.07125) | [PDF](https://arxiv.org/pdf/2610.07125)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 PEV 越狱攻击，仅对 prompt 的 embedding 向量加独立高斯噪声即可诱导开源 LLM 产生不安全响应，无需梯度、逐 prompt 优化或改权重。

**核心贡献/观点**：
- 极简越狱：PEV 仅在嵌入层加噪声、反复采样，比梯度/优化类攻击成本低一个数量级。
- 覆盖六款常见开源 LLM，对 JailbreakBench 全部 prompt 均产生不安全响应。
- 将「embedding 扰动下的 LLM 行为」确立为兼具安全风险与动力学探索价值的研究方向。

**关键结果**：首个成功越狱通常在 1 分钟内出现，平均计算成本比现有攻击低一个数量级，且无其他方法达到同等效果。

### [[Minimal_Witness_Reinforcement_Learning|Minimal Witness Reinforcement Learning]]
- **作者**：T. Y. Tsui, Zihao Ye, Pengxiang Cai, Yanchao Li, Yuqiang Li, Zhehong Ai
- **链接**：[arXiv](http://arxiv.org/abs/2610.07226) | [PDF](https://arxiv.org/pdf/2610.07226)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：将「最小充分证据识别」形式化为 MWRL，用单一黑盒 verifier 的反馈恢复整族最小 witness，而非返回单一解或冗余超集。

**核心贡献/观点**：
- 最小 witness 识别问题形式化，把「最小性」与「替代解恢复」统一到覆盖损失中。

- 提出值迭代规划器与可扩展到 LLM 的策略梯度方法。

**关键结果**：跨多个实验设置恢复大部分最小 witness，优于返回冗余超集或单一解的基线方法。

### [[Learning_to_Read_the_Contextual_Tokens_in_Diffusion_Transformers|Learning to Read the Contextual Tokens in Diffusion Transformers]]

### [[H-JEPA_End-to-End_Learning_of_Hierarchical_World_Models_for_Visual_Planning|H-JEPA: End-to-End Learning of Hierarchical World Models for Visual Planning]]
- **作者**：Wancong Zhang, Basile Terver, Michael Rabbat, Yann LeCun, Randall Balestriero
- **链接**：[arXiv](http://arxiv.org/abs/2610.06805) | [PDF](https://arxiv.org/pdf/2610.06805)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出端到端分层 JEPA 世界模型，每层在各自潜空间预测更远未来，自顶向下规划实现长时程视觉规划。

**核心贡献/观点**：
- 动作条件的分层 JEPA，各层在独立潜空间预测不同时间尺度。
- 自顶向下规划：上层优化目标进展，其预测成为下层规划器的子目标。
- 时间尺度分解使高层丢弃快变不可预测细节、保留慢变任务相关状态。

**关键结果**：在 Visual AntMaze 上三层分层使成功率从 18% 提升到 73%（更低 planner 计算）；在 DROID 真实机器人视频上提升离线规划保真度。
