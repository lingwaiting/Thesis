## 今日概览

今日推荐的 10 篇论文主要聚焦于**Agentic 训练与多智能体通信**、**推理评估与自我纠错**和**机器人决策与具身智能**等前沿方向。

- **总体趋势**：今日论文呈现三条主线——一是"智能体能力与通信机制"的再审视（区分任务能力与接口能力、解耦 latent 通信、LLM agent 社会涌现），二是"推理与评估的可靠性"（推理评估器自我纠错校准、街道级空间感知评测），三是"具身智能与训练效率"（机器人成本敏感决策、单阶段视觉 RL、残差接口扩展、学习率迁移）。多篇工作体现一种共同取向：把"黑盒增益"拆开，追问它到底由什么机制带来、是否可信、是否划算。
- **质量分布**：今日推荐的论文评分在 8.50–9.03 之间，整体质量较高且分布紧凑，前三篇（任务/接口能力分解、LatentLens、SwiftLoop）均属"智能体/推理机制解耦"主线，方法视角新颖。
- **研究热点**：
  - **智能体能力的可分解性**：Learning What vs. Learning How 将智能体能力拆为"任务能力"与"接口能力"，LatentLens 追问多智能体 latent 通信的真实贡献，二者共同挑战"增益必然来自被吹捧的组件"这一默认假设。
  - **推理与评估的可信度**：LUCID 用提示自我纠错 + DSL 校准推理评估器的系统性评分偏差，LimoBench 揭示 LLM 街道级空间知识几乎为零但接地后近乎完美。
  - **具身智能的成本与效率**：CATWAY 用成本敏感三路决策门处理机器人指令，DRIFT 用冻结视觉编码器实现单阶段 sim-to-real 视觉 RL，GHC 与学习率迁移则聚焦训练效率。
- **阅读建议**：建议先读前 3 篇（任务/接口能力分解、LatentLens、SwiftLoop），它们评分最高且同属"智能体/推理机制解耦"主线，可形成连贯认知；关注具身智能的读者可读 CATWAY 与 DRIFT；关注评估可信度的可读 LUCID 与 LimoBench。

### [[Learning_What_vs._Learning_How_Decomposing_Task_and_Interface_Competence_in_Agentic_Training|Learning What vs. Learning How: Decomposing Task and Interface Competence in Agentic Training]]
- **作者**：Chaeeun Lee, Hossein A. Rahmani, Aryo Pradipta Gema, Kexin Xu, Emine Yilmaz, Pasquale Minervini, T. Ian Simpson, Chen Jin, Amrutha Saseendran
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31427) | [PDF](https://arxiv.org/pdf/2611.31427)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/Learning_What_vs._Learning_How_Decomposing_Task_and_Interface_Competence_in_Agentic_Training|Learning What vs. Learning How 详细分析]]

**一句话总结**：将智能体能力分解为"任务能力(task competence)"与"接口能力(interface competence)"，揭示 harness 条件训练下二者的相互作用，并提出 harness rehearsal 解耦任务与接口监督。

![[2611.31427_hero_figure_page1.png|600]]

**核心贡献/观点**：
- 提出任务能力 vs 接口能力的两分法，解释为何模型"拥有任务知识却无法通过特定 harness 表达"这一失败模式。
- 发现多 harness 蒸馏虽能聚合任务知识，但只有训练保留/提升推理时接口能力时才能被实现；单 harness 训练会诱导接口能力干扰，甚至在 held-out harness 上灾难性坍塌。
- 提出 harness rehearsal（在几乎不含任务知识、仅锻炼目标接口的轨迹上蒸馏），与跨 harness 任务监督组合时收益远超单独使用。

**关键结果**：BFCL V3 多轮 + Qwen3-4B 上，跨 harness 任务监督与 rehearsal 单独分别 +8.5% / +32.5%，组合达 +58.8%；on-policy RL 比蒸馏对单 harness 训练更鲁棒，接口能力经多 harness 蒸馏后可延续到后续 RL。

### [[LatentLens_Rethinking_Latent_Interface_in_Multi-Agent_Systems|LatentLens: Rethinking Latent Interface in Multi-Agent Systems]]
- **作者**：Ziqing Yang, Kewei Cheng, Mingjie Li, Yang Zhang
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31582) | [PDF](https://arxiv.org/pdf/2611.31582)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/LatentLens_Rethinking_Latent_Interface_in_Multi-Agent_Systems|LatentLens 详细分析]]

**一句话总结**：提出 LatentLens 框架，在两级解耦多智能体系统的 latent interface——外部从 harness 解耦以度量其对整体性能的贡献，内部分解为 realignment 兼容性、信息可及性与传播动力学。

![[2611.31582_overview_v3_page1.png|600]]

**核心贡献/观点**：
- 外部解耦 latent 通信与 agent harness，回答"latent interface 对整体性能的真实贡献是多少"（RQ1）。
- 内部分解为 realignment compatibility、information accessibility、propagation dynamics 三个维度，定位各自的收益与局限（RQ2）。
- 指出 latent 表征虽保留领域信息，但"保留信息"不等于"有效通信"。

**关键结果**：七个基准 + Qwen3 上，在同一 harness 上加 latent interface 不提升甚至显著降精度；不兼容的 realignment 会大幅降性能，重复 latent step 会放大表征级失败。

### [[SwiftLoop_Selective_Refinement_for_Adaptive_Implicit_Reasoning_in_Looped_Transformers|SwiftLoop: Selective Refinement for Adaptive Implicit Reasoning in Looped Transformers]]
- **作者**：Tianyi Zhao, Ke Wan, Chen Chen
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31481) | [PDF](https://arxiv.org/pdf/2611.31481)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/SwiftLoop_Selective_Refinement_for_Adaptive_Implicit_Reasoning_in_Looped_Transformers|SwiftLoop 详细分析]]

**一句话总结**：提出推理时选择性递归细化框架 SwiftLoop，通过 position-wise freezing 在递归深度与激活宽度两个维度自适应分配计算，缓解固定深度循环的冗余。

![[2611.31481_motivation_loops_drift_page1.png|600]]

**核心贡献/观点**：
- 用 position-wise freezing 实现选择性递归细化，解决现有 looped reasoner 固定深度、每步更新所有 latent 位置带来的冗余。
- 通过 hindsight-guided 监督学习轻量 freezing 策略，源自两个互补准则：K/V 复用性（内部表征层）与功能影响（输出层）。
- 推理时根据观测到的隐藏状态引导自适应 freezing，并可迁移到一般 looped 模型的 recurrent prompt prefilling。

**关键结果**：相比 fixed-loop 推理与自适应基线取得更好的精度-计算量权衡，并有实测推理加速；在隐式推理之外验证了其对循环 prompt 预填充的适用性。

### CATWAY: Cost-sensitive agentic three-way robot decisions with calibrated language-model confidence
- **作者**：Erik Derner
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31694) | [PDF](https://arxiv.org/pdf/2611.31694)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出成本敏感的"三路决策门"CATWAY，用损失矩阵在概率单纯形上确定机器人指令的执行/询问/拒绝区域，并基于校准的语言模型置信度行动。

**核心贡献/观点**：
- 首个从误差成本推导全部阈值、并基于校准概率行动的机器人指令门，区别于"直接提问/成本感知提示/无保护 agent"。
- 将十样本投票与模糊性、不可行性、风险的分级打分通过逻辑回归融合为校准概率。
- 在家庭指令域拟合后冻结，跨两个新机器人域与外部 TRUST-NAV 基准验证。

**关键结果**：18 个家庭场景对比中显著更便宜（平均每项损失 0.28 vs 0.57–0.83），142 个不安全指令零执行；跨领域与 TRUST-NAV 上从不显著更贵。

### LimoBench: How Street Smart Are Large Language Models?
- **作者**：Gautam Choudhary, Jack Peng, Udesh Kumarasinghe, Rachel Rafik, Yousef Hammad, Ahmed Samy, Walid G. Aref
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31682) | [PDF](https://arxiv.org/pdf/2611.31682)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出街道级地理空间基准 LimoBench（82 个自然语言位置查询，覆盖 7 类空间操作），评测 LLM 的街道级空间感知，并给出基于 MCP 的接地工具集 Limo。

**核心贡献/观点**：
- 构建 LimoBench，将查询接地到西拉法叶真实地图数据，覆盖地理编码、路由、方向、范围搜索、kNN、空间连接等操作，按位置与语义复杂度分级。
- 提出 Limo（基于 Model Context Protocol），用 PostGIS 空间数据 + 紧凑工具集为 LLM 接地。
- 揭示未接地模型空间能力极弱，接地后近乎完美。

**关键结果**：未接地模型多为单数字精度（GPT-6 Luna 3.1%），接入 Limo 空间工具后达 99.3%；开销仅 +0.2s 延迟、7.7× tokens、2.2× 成本。

### LUCID: Statistically Grounded Self-Correction for LLM Reasoning Evaluation
- **作者**：Satiyabooshan Murugaboopathy, Adel Daoud, Connor T. Jerzak
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31595) | [PDF](https://arxiv.org/pdf/2611.31595)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 LUCID，将提示自我纠错与 Design-based Supervised Learning(DSL) 结合，无需重训练或权重访问即可校准 LLM 推理评估器的逐步评分偏差。

**核心贡献/观点**：
- 用提示自我纠错 + DSL 校准二进制逐步评分的系统性误差，将预测与专家的 soundness 率对齐。
- 从小规模专家标注集总结评估器偏差，提示其重新打分未见步骤，并支持跨模型/跨域迁移。
- 用 pre/post-check 过滤已校准评估器、回滚无效纠错轮次，避免仅移动阈值而不提升判别力。

**关键结果**：PRM800K 上 GPT-5-mini 的校准差从 7.8 降至 0.9 个百分点（单轮），错误告警减半，unsound 步骤的检测 F1 提升 32%。

### GHC: Expanding Residual Interfaces in Hyper-Connections
- **作者**：Tianyu Li, Hongtao Zhang, Dongchen Han, Jingshu Liu, Bojun Wang, Chen Jiang, Yulong Huang, Wei Chen, Tianyu He, Xiangyu Zhang, Gao Huang
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31350) | [PDF](https://arxiv.org/pdf/2611.31350)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 Grouped Hyper-Connections(GHC)，按注意力头/FFN 通道把每个分支划分为并行组，为每组提供独立流混合并加权聚合，扩大 Hyper-Connections 的残差读写接口。

**核心贡献/观点**：
- 针对 Hyper-Connections 每个分支只能读单一流混合、写同一输出向量到所有流的窄接口瓶颈。
- 按并行组划分分支，每组获得独立流混合，输出用可学习权重聚合到各流。
- 以可忽略的参数与内存访问开销，在稠密与 MoE 模型上稳定超越 IHC。

**关键结果**：训练效率比 Pre-Norm 高 35%、比 IHC 高 10%；扩大残差接口克服了加流的边际收益递减，更宽的残差状态带来进一步增益。

### Training decision models for simulating human respondents
- **作者**：Davood Wadi, Yu Ma
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31613) | [PDF](https://arxiv.org/pdf/2611.31613)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：训练"决策模型"(System One 架构) 作为硅采样(silicon sampling)的合成受访者，用条件极大似然在历史个体级选择微观数据上更新权重，降低下游计量推断偏差。

**核心贡献/观点**：
- 用 choice training 更新 KEV 模型权重，训练于历史受访者级选择微观数据，推理前进行、无需目标研究数据。
- 小规模选择训练模型在多数留出研究上优于更大的 off-the-shelf 生成式 LLM。
- 指出在单一研究上训练虽降交叉熵，却可能加剧处理效应误差。

**关键结果**：在四个跨领域（疫苗、营养标签、消费者权益、AI）留出研究上，处理效应误差降低 22%–89%。

### Reproducible Social Structure Emerges From Free-Form Interaction Among LLM Agents
- **作者**：Tom Alisch, Sonia Murthy, Robert Hawkins, Felix Sosa, Core Francisco Park
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31543) | [PDF](https://arxiv.org/pdf/2611.31543)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：用可重复、无目标、主动的多智能体框架（50 个带持久记忆的人格化 agent 在三个社交平台）在 10 次重复运行中研究 LLM agent 社会涌现结构的可复现性。

**核心贡献/观点**：
- 提出可重复的多智能体框架，支持跨时间快照与重复的非扰动测量，区分"系统固有规律"与"单次随机事件"。
- 发现多数网络级/agent 级参数跨重复稳定，且相同 dyad 跨世界重现显著高于偶然或 agent 社交性本身所能解释。
- 发现静态人格相似度无法预测 dyad，而首轮接触时的情绪/特质对齐与极端性才是预测因子。

**关键结果**：10 次运行共 700 小时；persona 提示或记忆移植使受体向供体人格靠拢约 60%，状态移植的 agent 从下一轮起即表现接近供体。

### One Phase Is Enough: Sim-to-Real Transfer with Direct Visual Reinforcement Learning
- **作者**：John Marangola, Antonia Bronars, Younghyo Park, Stephen Andrews, Kushal Kedia, Pulkit Agrawal
- **机构**：--
- **链接**：[arXiv](https://arxiv.org/abs/2611.31588) | [PDF](https://arxiv.org/pdf/2611.31588)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：提出 DRIFT，用冻结的预训练基础视觉编码器实现高效单阶段视觉强化学习，直接从视觉观测完成 sim-to-real 迁移，省去两阶段的教师蒸馏。

**核心贡献/观点**：
- 关键洞见：冻结预训练视觉编码器，让 RL 专注于从现有视觉表征学控制，避免通过视觉骨干的昂贵反向传播。
- 冻结编码器 + 预训练表征使从快速栅格化仿真渲染到真实世界的迁移成为可能。
- 在匹配架构、观测与算力预算下，单阶段视觉 RL 优于两阶段蒸馏。

**关键结果**：三个操作任务平均真实世界成功率相对提升 58.8%；仿真评估中相对优势从分布内约 9% 增长到分布外 61% 以上。
