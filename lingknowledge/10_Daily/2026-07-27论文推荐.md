**一句话总结**：提出 SkillsBench——首个系统化评估 Agent Skills 实际效用的基准，覆盖8个领域87个任务，揭示精简 Skills 优于大而全的捆绑包，小模型+Skills 可匹敌大模型。

**核心贡献/观点**：
- 提出**成对评估（paired evaluation）**方法论，在同一任务上对比有/无 Skills 的表现，消除无关变量
- 覆盖 8 个领域 87 个任务，配套确定性验证器，18 种模型-框架配置的大规模评估

**关键结果**：Skills 在不同配置下带来 +4.1 到 +25.7 个百分点的提升；小模型搭配 Skills 的表现可匹配无 Skills 的大模型；建立了 Agent Skills 效用测量的严谨基础。
