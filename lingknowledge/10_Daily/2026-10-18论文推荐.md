## 今日概览

今日推荐的 10 篇论文（与前日 top10 去重后顺延）主要聚焦于**智能体强化学习与对齐**、**具身智能与机器人操作**以及**LLM 评估与安全**等前沿方向。

- **总体趋势**：本批论文延续了对"智能体如何被训练与对齐"的密集关注——诚实对齐（CATCH）、多会话 agentic RL（Mosaic）、进度奖励模型（PRM4RL）分别从鲁棒性、轨迹结构、奖励设计三个角度推进智能体学习。同时具身智能方向显著升温：全身灵巧操作（WBD）、主动偏好学习、个性化操作基准（LIBERO-PeRM）、多智能体运动规划覆盖了从操作到规划的全链条。
- **质量分布**：今日论文评分在 8.43-8.9 之间，整体质量扎实。前 3 篇（评分 ≥8.8）分别聚焦诚实对齐、多会话 agentic RL、全身灵巧操作，均为值得深度阅读的工作。
- **研究热点**：
  - **诚实与安全对齐**：CATCH 把连续对抗训练迁移到诚实对齐，并揭示效用数据选择是能力保持的关键变量；同时智能体守卫的语言鲁棒性（LinguaGuardBench）暴露了安全评测的盲区。
  - **多会话智能体学习**：Mosaic 首次形式化多会话 agentic RL，用分层优化区分轨迹级全局信号与会话级局部贡献。
  - **具身智能全面开花**：从全身接触操作（WBD）、偏好学习（Active Preference Learning）、个性化基准（LIBERO-PeRM）到可审计多智能体规划（Posetal Games），方向丰富。
- **阅读建议**：建议优先阅读前 3 篇——CATCH（诚实对齐 + 能力保持）、Mosaic（多会话 agentic RL 新设定）、Whole-Body Dexterity（全身操作 sim-to-real）。第 16 篇 PRM4RL（奖励模型）和第 19 篇训练免蒸馏（Training-Free On-Policy Distillation）对关注 RL 与模型合并的读者也很有价值。

### [[CAT-alyzing_Honesty_Continuous_Adversarial_Training_for_Transferable_LLM_Honesty|CAT-alyzing Honesty: Continuous Adversarial Training for Transferable LLM Honesty]]
- **作者**：Yuan-Chen Chang, Niklas Herbster, Gauthier Gidel, Tommaso Tosato
- **机构**：Tara Research、Mila -- Quebec AI Institute、慕尼黑工业大学（TUM）
- **链接**：[arXiv](http://arxiv.org/abs/2610.22292v1) | [PDF](https://arxiv.org/pdf/2610.22292v1)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/CAT-alyzing_Honesty_Continuous_Adversarial_Training_for_Transferable_LLM_Honesty|详细分析]]
- **笔记**：[[20_Research/Papers/大语言模型/CAT-alyzing_Honesty_Continuous_Adversarial_Training_for_Transferable_LLM_Honesty|CAT-alyzing Honesty]]
- **评分**：8.9（相关性 3.1 / 新近性 3.0 / 热门度 2.0 / 质量 2.3）
- **领域**：大语言模型 → 诚实对齐

**一句话总结**：提出 CATCH，把安全对齐中的连续对抗训练迁移到诚实对齐，用仅数百个目标训练模型"推向诚实、远离说谎"，并证明 on-policy 效用数据是能力不退化、超越 SOTA steering 的关键。

![[fig1_overview_twoline_v25_page1.png|600]]

**核心贡献/观点**：
- 将连续对抗训练从安全对齐迁移到诚实对齐，解决诚实目标需逐例构造的难点
- 设计 CAT（unlikelihood + 效用项）与 CAPO（对抗式 IPO/DPO）双目标
- 揭示效用数据选择是能力保持的核心变量，on-policy 数据远优于 off-policy 的 UltraChat

**关键结果**：MASK 诚实率 Llama 34%→86%、Qwen 47%→91%；Among Us 认罪率 5%→84%（Llama）、19%→85%（Qwen）；AlpacaEval 与 Base 持平（51.3%/51.8%），而 steering 把 Llama 降到 8.6%。

### [[Mosaic_Multi-Session_Agentic_Reinforcement_Learning|Mosaic: Multi-Session Agentic Reinforcement Learning]]
- **作者**：Yilong Xu, Minrui Xu, Xinyu Zhou, Xiang Long, Haochen Tan, Zhijiang Guo
- **机构**：LARK, HKUST(GZ)、华为 Foundation Model Lab、香港城市大学、HKUST
- **链接**：[arXiv](http://arxiv.org/abs/2610.22174v1) | [PDF](https://arxiv.org/pdf/2610.22174v1)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/大语言模型/Mosaic_Multi-Session_Agentic_Reinforcement_Learning|详细分析]]
- **笔记**：[[20_Research/Papers/大语言模型/Mosaic_Multi-Session_Agentic_Reinforcement_Learning|Mosaic]]
- **评分**：8.9（相关性 3.3 / 新近性 3.0 / 热门度 2.0 / 质量 1.5）
- **领域**：大语言模型 → 多会话 agentic RL

**一句话总结**：首次形式化"多会话 agentic RL"设定（应对 context compaction 与 subagent forking），提出无 critic 的分层优化方法 Mosaic——轨迹层用会话数校准优势、会话层用边际信息增益塑造优势，在更少会话下取得更高准确率。

![[figure1-single-session-vs-multi-session-3_page1.png|600]]

**核心贡献/观点**：
- 提出 session-aware 轨迹级优势估计，用中心化排名让"成功轨迹少用会话、失败轨迹多用会话"
- 提出 session-level 优势塑造，用边际信息增益作为无 critic 的 process supervision
- 按会话类型（normal/compact/subagent）分别归一化，消除分布偏差

**关键结果**：BrowseComp 上 compact 场景 38.86（vs broadcasting 35.31）、subagent 场景 32.46（vs 31.44），会话数更少（3.17→2.35）；相对 broadcasting 最高 +10.1%。

### [[Whole-Body_Dexterity|Whole-Body Dexterity]]
- **作者**：Conor Mc Gartoll, An Dang, Pranay Thangeda, Arjun Gupta, Carolina Higuera, Nima Fazeli, Mustafa Mukadam, Manikantan Nambi
- **机构**：Amazon、加州大学圣地亚哥分校（UCSD）、密歇根大学（UMich）
- **链接**：[arXiv](http://arxiv.org/abs/2610.22184v1) | [PDF](https://arxiv.org/pdf/2610.22184v1)
- **来源**：arXiv
- **详细报告**：[[20_Research/Papers/强化学习与智能体/Whole-Body_Dexterity|详细分析]]
- **笔记**：[[20_Research/Papers/强化学习与智能体/Whole-Body_Dexterity|Whole-Body Dexterity]]
- **评分**：8.8（相关性 3.3 / 新近性 3.0 / 热门度 2.0 / 质量 1.2）
- **领域**：强化学习与智能体 → 全身灵巧操作

**一句话总结**：提出 Whole-Body Dexterity 框架，把人形机器人的手臂和躯干都当作接触面来抓取操作物体，通过"抓取生成 → RL 专家训练 → 蒸馏"三阶段 pipeline 实现 zero-shot sim-to-real。

![[method_new_v5.png|600]]

**核心贡献/观点**：
- 把接触面从末端执行器扩展到全身，形式化抓取模式 L/B/R 与 goal graph（handoff 必经双臂）
- 目标只指定物体位置 + 抓取模式（不含朝向/关节配置），催生人类式滑动/滚动接触
- 蒸馏成条件扩散 + 逆动力学控制器，仅用本体感觉 + 几何描述符，支持人类遥操作引导

**关键结果**：真实世界全身操作完成 90% 试验（vs direct retargeting 18%、通用全身控制器 4%）；完成夹箱搬运放置的长程任务。

**一句话总结**：把奖励学习中"识别出哪些特征被监督不足"的责任从人转移到机器人——用 informed prior 把偏好查询定向到需要消歧的特征，并附解释聚焦人的注意力。

### [[Language_Is_a_Security_Surface_for_Agent_Guards|Language Is a Security Surface for Agent Guards]]
- **作者**：Hasan Demirkiran, Jens Ernstberger
- **机构**：--
- **链接**：[arXiv](http://arxiv.org/abs/2610.22244v1) | [PDF](https://arxiv.org/pdf/2610.22244v1)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：发现步骤级智能体守卫（agent guard）的判定会随用户请求的语言而变化——构建 LinguaGuardBench，仅翻译用户指令、保持其余字节一致，揭示守卫在低资源语言上更不稳定。

**核心贡献/观点**：
- 构建 LinguaGuardBench（1220 标注步骤），只翻译用户指令、其余字节不变，把判定变化归因于语言

- 覆盖 19 个守卫（前沿 API 到 4B 开源模型与 4 个专用守卫）

**关键结果**：9 个 13B 以下守卫中，placebo 调整后的翻转率从法语 +1.5pp 升至阿姆哈拉语 +4.4pp；专用守卫最敏感，方向随守卫规模分化；前沿守卫变化约 1 点以内。

### [[Training-Free_On-Policy_Distillation|Training-Free On-Policy Distillation]]
- **作者**：Bangji Yang, Jiajun Fan, Zhaoyu Zhu, Hongbo Ma, Ge Liu
- **机构**：UIUC、清华大学
- **链接**：[arXiv](http://arxiv.org/abs/2610.22236v1) | [PDF](https://arxiv.org/pdf/2610.22236v1)
- **来源**：arXiv
- **笔记**：--

**一句话总结**：证明 on-policy 蒸馏可以完全免训练——当专家共享基模型时，仅用前向传播即可聚合多个专家，每个线性层的最小二乘闭式解让融合模型平均比任一专家更准。

**核心贡献/观点**：
- 揭示 on-policy 蒸馏存在逐层精确解，只需专家输入的二次矩
- 仅数百个 rollout 的前向传播即可完成，无需梯度步
- 数据内容比求解器更重要：剔除重复循环截断的答案显著提升融合效果

**关键结果**：Olmo 3 7B 上每个专家数 GPU 小时的前向计算即得到通用模型，在 7 个数学与代码基准上保留大部分专家增益；AIME25 上融合模型达到专家水平。
